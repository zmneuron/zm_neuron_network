# 生物学变化、机制依据与场景修改

用于环境暴露、疾病、药物、刺激、发育/衰老等条件，以及它们的组合。沿用主流程中的调研、方法、构建和比较，只展开与本次问题有关的内容；只调研或改技能时不启动模型。本文的文献实例用于判断方法，不提供统一疾病参数或封闭的场景目录。

当本轮还要改善疾病或环境影响时，按“基础模型—负面影响—调控”衔接[调控细则](regulation-design.md)。本页负责生物学变化、病理表示与状态历史；调控细则负责方法/协议选择和实际作用的筛选，复用这里的参考与比较，不把三部分拆成三套工程。

## 先查发生什么，再查为什么

从研究对象、条件、阶段及目标现象定位问题，按[需求与用途](scientific-questions.md#从现实需求定位本轮用途)明确要解释的困难及本轮贡献；疾病、环境或干预名称本身不能决定脑区、机制和倍率。调研按下列关系推进，新结果可返回相应调查；不是一次写完的问卷。

| 研究内容 | 需要查到并写清什么 | 对模型的决定 |
|---|---|---|
| 发生了什么生物学变化 | 原始实验测到的量、方向、幅度/范围、分布及时间过程；物种、年龄、亚型、部位/细胞/区室、阶段、制备、暴露和测量协议；相对什么对照 | 定义待解释现象及适用范围，区分活动、数量、形态、表达量与功能变化。没有幅度证据时不编造百分比。 |
| 为什么可能发生 | 相关性、时间先后、直接操纵及靶点响应、阻断/救援、剂量关系等分别支持哪一段作用关系；竞争解释、补偿和相反结果 | 明确已支持的关系、仍待检验的解释与缺失环节。机制研究有贡献但不自动排除间接作用或所有替代解释。 |
| 本模型需要表达什么 | 当前变量和边界能否表示该变化；现象复现、机制比较、预测或干预效应分别需要哪些中间量和输出 | 选择输入/状态/参数/机制/结构/观测修改，以及足够的脑区和分辨率；不因某过程真实存在就全部建入模型。 |
| 怎样由资料得到数值 | 来源图表/方程/数据或代码位置、原始量及单位、源条件与本次条件、转换关系、固定/推导/待估的身份及范围 | 得到可执行的值或规则；未知但可探索的部分明确标为假设，并安排能约束它的比较。 |
| 运行后怎样判断 | 实际生效量、直接靶点或区分性中间结果、主要终点、对照与实测差异 | 分别判断实现是否一致、输出是否相容、机制是否仍有替代解释；不能用调参后的终点匹配反过来证明原因。 |

采用多条直接相关的原始研究，优先比较独立实验、相应方法/补充材料和实际代码；完整新建的篇数建议仍按[方法规则](construction-methods.md)。不把同一实验的论文、数据镜像及代码算成独立重复，也不以固定篇数结束每轮。观测证据与机制证据可以来自不同研究，但要说明条件能否对应、哪些环节是本项目推断。表达量、功能电流与发放率不能自动作同比例转换。

原因尚未确定时，仍可开展表型拟合、有效模型或少数候选比较；如实写“原因未明/本次检验的假设”，不得补写成定论。若多个参数组合都能产生同一现象，增加对当前选择有区分力的观测，或报告无法区分。相似活动可能来自不同参数组合已有原始模型研究支持，具体可识别性仍由本项目的数据与问题判断。[Prinz 等，2004](https://doi.org/10.1038/nn1352)

用户提供的资料也要逐项核查其来源、条件和逻辑，原文声称“已读取/已运行”不能直接变成本次完成记录。文献冲突先查阶段、对象、协议和测量定义；不能直接平均不兼容的倍率。每轮有实质发现后，按[交流规则](interview.md)和所选档位分批讨论尚未决定的研究取舍，例如形成过程或已形成状态、目标功能与优先读数、机制解释或表型预测；公开事实与技术换算由 AI 查证。

## 脑区范围与表示分别选择

用户未指定脑区时，依据“目标现象—作用路径—可观测量—可用约束”给出优先方案；仅有实质差异时给一个有条件的备选，说明什么新目标或证据会改变选择。已有某脑区代码不能成为把所有疾病都放入该脑区的理由。

分别确定解剖范围、动力学表示、空间分辨率、真实计算的时间尺度。多脑区可采用逐神经元模型，局部模型也可采用群体方程。只有问题依赖远端反馈、传播或分布式读数时才扩大范围；已测外部轨迹足够回答问题时可作为输入，不强制建全身系统。研究行为反馈或自主适应时再判断是否需要闭环。

相关脑区、干预靶点、较早出现病理的部位与原发病因分别说明。结构连接、功能统计关系和生成模型推断的有效连接不能直接互换：功能反相关不定义直接抑制性突触，流线数也不能直接当轴突数、接触数或电导。纤维追踪的原始验证研究支持这种谨慎映射；其历史错误率不能直接赋给当前所有数据。[Maier-Hein 等，2017](https://doi.org/10.1038/s41467-017-01285-x)

跨区或混合表示需要在现有方法和模块中补齐以下信息，不另建全脑要素清单：

| 对象 | 必须明确定义的关系 |
|---|---|
| 节点与局部动力学 | 区域/左右侧/层/群体及数量或代表范围；实际方程、状态和观测含义；图谱及坐标转换。 |
| 每类跨区投射 | 来源→目标及作用位置、结构/统计/有效关系、递质或作用符号依据、数量或概率、单位贡献/总贡献、过滤/受体动力学、时延、归一化和不确定性。 |
| 区域量到细胞连接 | 明确生成规则及独立控制量。例如可交换细胞对假设下，来源入度期望为 `N_available × p`，接触入度还乘已连接细胞对的条件平均接触数；实际抽样、自连和异质性另行处理。区域相对强度还需要总输入预算及目标分配依据。 |
| 缩小网络 | 说明要保持的平均输入、波动、相关、时序或目标输出；数量、入度、权重、背景和补偿怎样联动。相同均值不保证相同动态。 |
| 跨尺度接口 | 交换的是每细胞平均率、总事件率、电流还是电位；汇总/过滤、来源数、噪声与相关、延迟及交换间隔。显式来源替换其已有背景代理，避免重复。 |

独立泊松来源、固定线性核等假设下，输入均值正比于 `K w r`，方差正比于 `K w² r`。仅缩放同一个权重通常无法同时补偿来源数的减少；同一来源同步激活的多个接触也不等于多个独立来源。已有多区域实现同时调整权重与直流补偿，但不能据此保证同步、传播和场景效应都不变；按目标检查。[Schmidt 等，2018](https://doi.org/10.1371/journal.pcbi.1006359)；[对应实现](https://github.com/INM-6/multi-area-model/blob/master/multiarea_model/multiarea_model.py)

群体表示按[逐项规则](element-coverage.md)写具体约化或不适用理由，保留原编号及目标必需项，不伪造细胞级坐标、通道或接触数。显示布局不作为物理路径长度，群体率转为泊松输入时产生的变异与相关假设也要记录。

## 把依据落实到直接改动

每项实质改动给稳定标识，关联生物学发现、原因依据和参数/模块/结果；同一作用路径可合并叙述，但所有实际改动都须能定位。建模选择、数值设置和技术修复分别给理由，求解步长不能解释为病情严重程度。

按[科学约束](scientific-constraints.md)检查改动究竟发生在哪里。仅改变下游有效增益而保持局部细胞/连接不变，可以研究该路径假设，不能同时宣称复现了局部细胞病理。区域名称、通用 E/I 比例或末端表型相似不足以确定脑区/疾病特异机制；应补目标依赖的约束，或明确当前只支持情境下的有效模型。候选机制可保留，不把无法量化的影像、标记或行为变化直接换成突触倍率。

| 修改层级 | 对应操作与关键区别 |
|---|---|
| 输入或边界 | 改模型外部的实际作用量及时间函数。吸入氧、储库氧和局部组织氧不同；给药量和作用部位浓度不同，需要明确映射。 |
| 初态或准备 | 指定已有历史或阶段状态及来源；单改初态不能自动表示持续病因。 |
| 参数或规定关系 | 给 `基准值→场景值` 的公式、单位、范围、对象和有效时间窗；比例、偏移、动力学曲线与时程各有适用条件。规定轨迹属于输入，不能声称模型预测了该轨迹。 |
| 机制或方程 | 目标所需反馈、记忆、作用靶点或区分能力缺失时，按[机制接入](mechanism-extension.md)新增/替换。可能只需代数关系，不默认增加一套慢系统。 |
| 形态或拓扑 | 改数量、存在性、位置、面积或接触生成规则；说明密度与总量、来源与接触、存活群体分母及补偿。 |
| 观测或分析 | 改测量映射、记录协议或分析定义；独立说明它是否影响动力学，比较时保持适用的同口径。 |

在当前方法中用简短文字或关系图区分：**外部规定/直接施加 → 内部状态与通量 → 观测结果**。已由方程计算的后果原则上作为输出：如离子浓度已决定反转电位，就不再施加同一病理的电位偏移；显式清除已产生突触损失，就不重复手动删边。额外钳制可以作为另一个明确命名的实验，不能混入原场景而不说明。

涉及实际行动时，再明确“可实施的动作 → 作用部位及时间过程 → 本模型输入、参数或结构”的转换，注明个体条件、作用范围与有依据的其他效应；抽象增益或有效耦合可能综合多个过程，不能仅凭名称对应单一受体或病因。输出端分别核对内部状态到实际可测信号、再到目标功能/结局的联系，后者没有依据时保留为缺口，不把拟合关系或参数复原改称治疗效果。这些关系写入现有方程、参数与协议，不强制每个模型增加全身过程或临床结局方程。

同一暴露具有多项独立直接作用时可以联合改变，不规定“一次只能改一个参数”。Soplata 等的特定药物模型同时改变 GABA_A 电导和衰减；其 `spm` 已作用于两处，且电流按来源数归一化，移植时必须读实际运行覆盖值及公式。它支持该表示，不给所有药物提供共同倍率。[论文](https://doi.org/10.1371/journal.pcbi.1005879)；[机制代码](https://github.com/asoplata/propofol-coupling-2017-mechanisms/blob/master/models/iGABAAChing2010.mech)

数量、释放与效能不能由一个终点各自确定。例如在线性相加近似下 `J≈Npq`，响应剩 20% 只约束其乘积；三项都乘 0.2 会使乘积变成 0.008。该算例不提供生理参数，也不能代替带饱和、驱动力变化或短时程可塑性的实际方程。参数和历史状态须分别处理；NEST 的 `tsodyks2_synapse` 中 `U/u/x` 含义及初始化要求是版本相关的，不能照变量名再乘一次释放概率。[NEST 3.9 定义](https://nest-simulator.readthedocs.io/en/v3.9/models/tsodyks2_synapse.html)

按[参数对应](construction-methods.md#把来源数值对应到本模型参数)保留来源原量、采用值与转换。几何改变时先确定固定总量还是固定密度；动态体积需要核对浓度与物质的量关系 `n=cV`，据采用的近似处理体积变化项。论文使用的近似也要审查，不自动成为新模型的通用恒等式。Ullah 等明确说明省略了部分体积引起的浓度项；复现该版本与建立要求严格守恒的新模型应分别处理。[Ullah 等，2015，方法](https://doi.org/10.1371/journal.pcbi.1004414)

配置从固定参考与本次变换解析，保存最终生效值；重复加载不得累乘倍率。累计损伤由显式动力学或累计变量产生。核对同一总因子是否在运行入口、机制和归一化中重复计入，派生量是否被旧缓存覆盖；共享靶点、资源和相关参数按同一适用关系处理。

## 参考模型与连续历史

场景应在选型时参与决定入口与观测，不必等模型全部建好才考虑。新场景仍须检查现有模型是否适用；必要时扩展正常参考或重选范围。当前任务的参考可以是健康、无暴露、术前或另一个指定阶段，不能仅凭“基线”字样宣称健康状态已得到验证。

新增正常与异常中都存在的生理过程时，先建立包含它的参考模型 B1，再比较 B1 与场景 S。原模型 B0 用于检查表示变化；B0 对 S 的差异不能单独归因于场景。重校准使用约定的参考数据及约束，保留改变原因和 B0/B1 结果；不要求随机轨迹逐点重合，也不为方便产生病理而暗调参考。仅在异常条件激活的过程可在参考条件下零激活，正常稳态过程不能随“疾病模块关闭”一起删除。

显式机制接管旧有效过程时明确替换范围。Brown 与 Loew 在显式钙生化区室移除了原简化钙壳，而其他区室保留旧表示；这种局部替换比按模块名称简单叠加更有参考价值。[Brown 与 Loew，2012，方法](https://doi.org/10.1186/1752-0509-6-70)

| 协议 | 状态处理与可支持的时间解释 |
|---|---|
| 独立条件/阶段比较 | 各条件按明示规则准备。使用第 30 天的参数运行秒级活动，只代表该阶段，未模拟 30 天形成过程。 |
| 急性暴露/干预/撤除 | 按同一连续历史推进，或在指定时刻从同一完整状态分叉；更改外部作用后由内部动力学响应。 |
| 规定时程 | 使用实测或假设的轨迹驱动，说明预测的是响应；不自动成为内生适应模型。 |
| 形成、迟滞或恢复 | 需要能表示相关时间尺度的状态及约束；撤除作用后保留离子、受体、适应、损伤和结构的应有历史。 |

“继承状态”按实际后端包括必要的细胞/突触状态、共享介质、事件队列/延迟、时间基准与随机过程。拓扑或状态维度改变时定义对象对应和新状态准备；零初值不能通用，复制旧检查点也不能恢复从未计算的历史。不能完整续接时，可从共同准备阶段重跑或明确近似映射及影响，不能声称精确连续。

停药、复氧或恢复环境只按协议撤除作用；未建模再生的结构损失不自动恢复。记录哪些量立即可逆、逐渐恢复、持续保留或未知。区分自然恢复、直接病理与补偿，不能要求所有异常参数回到正常值。

默认有基础发放率适用于未另指定的网络建设；特定文献复现、暴露后的抑制/静默或非平稳病理按本次生理条件判断。**优化目标是更好解释相应数据和问题，不能为了满足正常发放目标消掉拟研究的场景效应。** 数值发散与计算有效的病理状态分开检查。

## 运行比较与结论

先确定本轮结论是表型拟合、候选机制比较、预测、干预响应还是理想反事实；同一项目可以包含多类结论，各自注明数据用途。依据不足以识别真实机制时，可以完成有效模型比较，但不能升级为已证明病因。

以可检验的最小机制组合接通到目标读数，不声称事前已知“因果充分”。检查直接改动和相关中间量后完成授权的目标条件、时长和重复。主要终点与有区分力的读数按问题选取；简单输入改变无需另造无意义的分子中间量。

- **场景效应：** 比较条件匹配的参考与场景，说明共同和不同的输入、参数、结构及历史。所有条件的实际有效参数、时窗和目标输出均保留。
- **干预效应：** 参考、场景和场景加干预用于描述；估计干预作用时，场景对照要在同一时间继续运行，采用相同撤除/供给等背景及适用的假刺激/载体。若环境撤除本身就是待评价干预，它应作为两组差异，而非共同撤除。连续恢复从可比的干预前状态分叉，不能只将晚期干预后与早期异常值相减。健康加干预在判断一般作用、特异性或交互时加入。
- **真实干预与反事实：** 干预从有依据的靶点、有效强度/暴露及介入时刻进入。直接把病理参数恢复或钳制输出可作理想反事实，不代表已模拟真实治疗；机制敏感性、理想恢复与可实施策略分别命名。预防既有损伤和逆转损伤需不同协议，功能改善与表面正常化按[用途比较](run-compare-optimize.md#面向具体用途的比较)分别判断。
- **联合效应：** 研究 A/B 交互时使用适用的参考、A、B、A+B；加性尺度上的 `Y_AB−Y_A−Y_B+Y_0` 仅是该尺度的交互量，不自动证明普遍协同。共享受体/资源依据饱和和竞争关系处理；只在顺序属于问题时比较 A 后 B 与 B 后 A。
- **不确定性：** 随机种子、结构实例、参数不确定性和真实个体差异分别报告。相同种子不保证实际输入或连接已配对；核查对象和事件。只在结论需要时比较少数同样满足参考约束的参数解，不按场景结果挑选参考解。

数据用途和优化沿用[运行与优化](run-compare-optimize.md)，同一科学问题累计记录失败、诊断和重跑成本，换条件名/窗口/优化器不清零。达到约定结束条件后保留支持、不支持、无法区分或超出范围的判定；阴性结果不触发无限增加机制，也不擅自取消原来必需的实测比较。
