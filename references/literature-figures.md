# 学习文献结果图，并用本模型数据重绘

在调研构建方法时同步阅读相关论文的结果图，在运行前确定本模型需要保存什么数据。学习图的科学用途、指标组合和表达方式，用本模型真实结果重新绘制。与[逐步结果交付](result-delivery.md)共用步骤、数据和图件标识。

## 从参考图到本模型图

1. **围绕问题找图。** 优先从直接相关的原始建模和实验论文中选择，通常先比较 2–4 篇中的关键图，再按缺口补充。不以期刊名或视觉风格代替科学相关性。覆盖适用的构建结构、组件响应、群体活动、条件效应与检查结果；不同图可借鉴不同论文。
2. **实际打开原图。** 查看出版物图页或渲染 PDF，结合完整图注、方法及补充材料，读清面板、单位、刺激、独立单位和误差条。记录 DOI/网址、版本、图号/面板及实际查看位置。只读到图注时标记“图注已读，原图待查看”，不能声称已核对配色、布局或图中细节。链接失效时换可访问的作者稿或原始来源，保留版本差别。
3. **拆解图回答的问题。** 逐面板记下科学目的、数据层级、横纵轴、指标算法、时间窗、平滑/归一化、样本筛选和统计方法。再提取布局、共享坐标、颜色语义、线型、刺激标记、面板标签和图注结构。若作者提供绘图代码，查看对应脚本/函数及版本，核对输入和聚合方法；只需绘图时不运行整个模型工程。
4. **对应到本模型。** 为每个拟绘面板指定构建步骤或研究问题、保存的数据标识/字段、计算方法、单位、条件和独立重复，列明保留与修改之处。膜电位、尖峰率、钙信号和突触电流按真实量绘制；实验动物、细胞与网络实例的层级不互换。跨物种、状态或协议的图可供表达借鉴，是否可作数值检验需另行论证。
5. **生成和改进图。** 在 `analysis/` 编写可复用绘图函数或配置，将数据读取、指标计算与图形样式分开；同类图复用字体、颜色、单位和版式。先用已保存的真实数据绘制，核对对应表，再渲染检查和调整。没有相应数据时标记待补，说明记录或计算需求，不为了凑面板虚构结构、实验或曲线。
6. **保存研究与成图。** 使用[图件调研与设计模板](../assets/figure_plan.md)写入 `docs/research/figure_plan.md`；已有相同内容则补入原记录。`analysis.json` 每张图用 `design_ref` 指向对应设计记录，同时保留数据、绘图代码、命令和图注。正式图保存可编辑矢量版本与必要预览，主要图逐一打开核对。结果报告说明借鉴来源及修改，原图只作为参考材料，不混入本模型的结果图。

## 模仿哪些部分，怎样判断适用

| 参考图特征 | 可采用的做法 | 本模型需要核对 |
|---|---|---|
| 结构示意与连接矩阵并列 | 用结构图解释对象，用矩阵展示有方向的连接规则或实际统计。 | 示意图和实际生成网络分别标明；行列方向、分母、空间坐标是否真实存在。 |
| 原始轨迹、群体曲线与个体点并列 | 连通原始活动、时间过程和单位间差异。 | 代表对象选择、独立单位与嵌套重复，不能只画最符合预期的试次。 |
| 刺激前后或条件间的配对图 | 保留每个单位的连接线，同时报告差值及适用的不确定性。 | 配对关系、各自背景/对照与缺失条件；借鉴图型不照搬论文的样本数、显著性或结论。 |
| 分布、矩阵、参数扫描 | 展示异质性、结构方向或已实施的参数比较。 | 分箱、归一化、色标、取值范围及扫描预算；有正负意义时保留零参考。 |
| 多面板组合 | 按“构建 → 组件 → 活动 → 比较/检查”组织本轮叙述。 | 每个面板有实际数据或明确的示意用途，图量服从问题，不照抄无关面板。 |

轴范围、颜色和线型服务于当前数据：同一比较保持可比尺度，截断、对数轴或归一化明确说明；不为接近参考图的外观改变模型参数、删除不利结果或重塑曲线。数据统计图使用绘图库从保存数据生成；示意图也要与实际启用机制一致。

## 本次样本相关的阅读实例

以下为 2026-11-21 修改技能时的阅读记录和应用建议。前两项已只读查看用户指定样本中保存的论文 PDF 并渲染原图；后两项读到在线正文/图注，原图未成功显示，仍是待核对候选。这里只学习表达与设计，没有对样本作重分析或生成新模型结果，也不授权未来自动读取该样本。

| 文献与图 | 已核对内容 | 可用于本模型的改编与限制 |
|---|---|---|
| [Gasselin 等，2021，Fig. 4 A–C](https://doi.org/10.1016/j.neuron.2020.12.018)；作者 PDF 第 7 页原图、第 8 页图注 | 已查看：每组从响应轨迹、细胞配对量到回路解释排列；标出刺激时刻。图注区分轨迹的 SEM 阴影与汇总点的 SD。 | 可借鉴“时程＋配对效应＋机制示意”的组织；本模型使用实际记录量和网络层级，不将其 Hz 曲线称作实验 Vm，也不把简化干预直接等同于 VIP 光操纵。 |
| [Avermann 等，2012，Fig. 4](https://doi.org/10.1152/jn.00917.2011)；作者 PDF 第 9 页 | 已查看：原始响应与重复响应叠加，并展示幅度/潜伏期随试次时间的变化及不同条件下的响应。 | 可借鉴组件响应、实际刺激标记和幅度/延迟核对图；本模型没有实施的药理、反转电位或膜电位扫描不照搬。 |
| [Jiang 等，2024，Fig. 3、6](https://pmc.ncbi.nlm.nih.gov/articles/PMC11439972/) | 正文/图注已读，原图待查看：有向连接概率及尖峰、放电率分布、相关与间隔统计。 | 是构建结构与群体活动图的候选；缩减网络按自身群体重绘，额外统计按问题及记录时长选用。来源规则矩阵与实际连接统计要区分。 |
| [Gutzen 等，2018，Fig. 5](https://doi.org/10.3389/fninf.2018.00090) | 正文/图注已读，原图待查看：将活动与统计分布用于比较实现。 | 是数值/实现比较图的候选；采用哪些统计量和允许差异由本模型目的决定，不能仅凭外观相近宣布一致。 |

上述改编是本技能的设计判断，不表示这些论文要求所有模型采用同一种图。具体任务仍需重新选择与当前科学问题相关的图，并完成原图和方法核对。
