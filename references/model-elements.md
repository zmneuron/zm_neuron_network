# 各脑区共用的十四类神经模型构建要素

AI 从用户的粗略描述开始查资料，随访谈填入已知内容。下表仅作导航，完整要求来自[原清单副本](construction-elements-checklist.md)的十四类、86 条详细事项及模块统一填写表。按[逐项落实规则](element-coverage.md)填写处理方式、决定、对应模块及实际检查，不能仅完成下表就宣称全部覆盖。代码按[网络组成划分模块](project-layout.md#按神经网络组成拆代码)，不按十四项机械拆成十四个文件。仅核查已有工程时保留原组织并逐项引用；用户委托整理时，按新路径同步说明与入口。

清单检查神经模型部分是否完整，不限定全部科学问题只能用这些表示。所需场、化学、观测或其他过程超出现有候选时，按[方法发现](method-discovery.md)继续研究，再接入实际模块与接口；保留原编号，不靠扩展软件菜单替代必要方法，也不为填写清单给纯场等明确限定任务虚构神经网络。

| 编号 | 类别 | 在建模说明中写清什么 |
|---|---|---|
| 01 | 研究目标与模型边界 | 对象、现象、输入与对照、目标输出、时空尺度，以及本轮结论覆盖哪些条件。 |
| 02 | 生物学背景与参考条件 | 物种、年龄或阶段、脑区和层次、制备或行为状态、温度和相关实验条件。标明原记录中缺失的关键信息。 |
| 03 | 计算单元与细胞群组成 | 群体身份及依据、动态细胞与外部事件源、原始数量或密度、体积、比例、缩放与取整、个体差异及最终各群体数量。说明缩减后保留或改变的性质，并核对实际细胞表。 |
| 04 | 空间布局、细胞形态与区室结构 | 分别说明布局、几何和电学区室。明确三维坐标系、单位、空间与层次边界、实测或生成位置的方法及随机设置；保存实际细胞坐标。记录形态、取向、突触与刺激位置；非空间模型明确不适用及影响。 |
| 05 | 神经元动力学与状态变量 | 方程或原机制及版本、状态和单位、输入进入的位置、放电产生或检测规则，以及温度处理。 |
| 06 | 参数、单位与个体差异 | 参数含义、来源原值与条件、换算公式及代入值、本模型实际值/范围/分布与单位、采用理由、配置字段及代码。区分直接采用、估计、拟合、推导和假设，并核对运行配置及个体取值。 |
| 07 | 连接结构与网络拓扑 | 列每条来源群 → 目标群，明确方向、候选集合、连接算法及矩阵行列。分别写伙伴数、每对接触数、入度或概率、空间条件、自连和重复规则。保存并核对实际连接。 |
| 08 | 突触动力学与可塑性 | 受体或耦合形式、后端权重的物理含义、电流或电导、反转电位、单接触强度及分布、时程、延迟与作用部位。保存实际突触参数；可塑性按需说明状态、更新和边界。 |
| 09 | 背景输入、任务输入与外部刺激 | 输入源及相关性、刺激波形与单位、靶细胞或区室、时段和对照。核对实际送达的输入。 |
| 10 | 特殊生理机制与模块耦合 | 按需处理额外机制。启用的模块写明输入、输出、单位、状态归属、作用方程、反馈和更新时间。省略或简化时写明影响。 |
| 11 | 初始状态与实验时间过程 | 初值来源、平衡或刺激前时段、刺激与恢复时间、各条件如何重新初始化或共享历史。 |
| 12 | 数值求解、随机过程与运行设置 | 后端、版本和入口、求解与记录步长或解析计算、随机来源与配对、重复单位、资源和复现方式。 |
| 13 | 原始记录与实验信号生成 | 区分内部变量、实际保存的原始量和用于比较的实验信号。写明观测映射、单位、时窗、记录对象、采样与预处理，保留支持结果的原始数据及字段说明。 |
| 14 | 分析指标、条件比较与完成标准 | 指标计算、比较对象、独立单位、拟合与留出划分、预设标准、可调参数与范围、累计预算及失配原因。在最终采用版本上复查原定约束，保存分析表、正式结果图及对应的原始数据、设置和生成代码。 |

## 从导航到具体决定

完整构建用原清单核对全部事项；早期调研只展开能改变当前选择的部分，不把此表当成一次性问卷。边查资料边按[分轮交流](interview.md)讨论，AI 负责来源、算法和参数调查，研究者参与目标与科学取舍。

研究来源、跨条件差异、参数转换与采用理由统一写入[方法及参数记录](construction-methods.md)，不再按本页建立另一套同义表。逐项处理及实际模块对应见[清单落实](element-coverage.md)；代码职责见[工程组织](project-layout.md#按神经网络组成拆代码)。

对每条所需通路，区分投射方向、细胞间连接概率、接触数和作用强度各自需要的来源；形态、空间、可塑性、局部环境与观测按研究问题启用。目标依赖机制不能以未找到代码为由省略，解释边界与实际检查随选择一起记录。结果的必要内容见[结果交付](result-delivery.md)。
