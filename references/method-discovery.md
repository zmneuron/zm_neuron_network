# 从研究问题发现方法与选择软件

用于初次选型、现有表示不能回答问题，或确需补充/更换实现时。并入已有“调研与讨论 → 形成方法 → 小规模检查”，不增加独立阶段、软件问卷或全领域模型清单。已有路线仍适用时直接复用；局部机制实现见[机制接入](mechanism-extension.md)，来源数值与记录见[构建方法](construction-methods.md)。

研究问题尚宽泛或需要深化时，先按[问题推敲与能力映射](scientific-questions.md)明确未知关系、不同预测和关键比较；本页负责用什么表示与实现来回答。新结果影响问题时只返回相关部分，不能用新增软件或机制代替科学问题的形成。

## 先明确终点和缺少的过程

依次连接 **研究问题与可用观测 → 必需过程 → 数学表示和尺度 → 输入、状态及输出 → 科学接口 → 实现候选**。必要时在当前方法中画简图，区分规定输入、实际求解过程和派生读数。先判断当前表示能否表达目标，再判断偏差是否来自参数、协议或实现；不能用不断调参替代缺失过程。

| 目标与现有表示之间的缺口 | 应发现和比较什么 | 不能跳过的关系 |
|---|---|---|
| 设备量、组织场到细胞响应 | 场求解、组织/细胞表示及适用作用机制 | 场强、声压或功率不是膜电流；需要物理与生物作用关系，不能仅换单位或改变量名。 |
| 内部神经活动到实验信号 | 与测量对应的观测模型及必要生理过程 | 发放率、膜电位、LFP、EEG/MEG、BOLD 与荧光不是同一量；源、几何、转换和采样需定义。 |
| 局部浓度、空间运输或能量反馈 | 反应、扩散/运输、电化学或适用有效表示 | 域、几何、边界、状态更新及膜过程接口；已有环境常数是否仍适用。 |
| 跨区活动、行为或环境反馈 | 群体/神经场、局部详细模型或身体环境关系 | 群体聚合/分配、尺度、反馈方向与交换时间；行为预测不自动证明细胞机制。 |
| 参数不唯一、模型太昂贵或目标仅需功能读数 | 可辨识性、实验设计、解析/稳态/降阶、代理或功能模型 | 保留量、适用输入范围、近似误差和参数含义；更复杂的推断不能弥补缺失信息。 |

这些行是发现缺口的示例，不是必须加入的模块。继续搜索未列出的过程；有依据的单向输入可以满足本轮问题，不默认构建双向全系统。若研究只需解析关系、稳态场或参数分析，可推荐相应方法。用户原本要求完整网络或生物响应时，不能把容易完成的场计算或局部分析改称原任务已完成。

## 点模型优先与形态需求

新建逐神经元网络且用户未锁定表示时，先比较满足[关键过程与观测约定](construction-methods.md#关键过程与观测约定)的点模型。这里的“点”是不解析细胞内部空间，不等于只能用 LIF，也不排除电导和离子状态；单区室 HH 类模型属于点表示。该优先顺序是本技能的建模选择，不是所有问题的科学定律。用户指定的复现、理论、群体/场模型和已有适用实现不因此强制改为点模型。

| 问题依赖的关系 | 表示选择与边界 |
|---|---|
| 发放、同步、回路反馈或适用的适应 | 比较能表达相应关系的 LIF、AdEx、GLIF、电导型点模型等；不因“详细”二字增加形态。有效状态的解释按其方程与数据范围。 |
| 特定离子电流或电压依赖的膜过程 | 优先采用有相应状态、门控及数据约束的单区室电导模型；有效适应参数不能仅改名为某种通道电导。 |
| 树突局部整合、突触位置效应、轴突传播或形态相关场作用 | 在必要细胞中解析足够的区室、电缆耦合与机制位置。经验证的约化空间模型可用，不默认重建全部分支；不足的点表示不能替代目标局部机制。 |
| 神经元间距离、三维排布及距离延迟 | 点模型可带网络坐标；这些关系本身不要求细胞内部形态。 |
| LFP/CSD、EEG/MEG 等实验信号 | 先核对源与观测转换；信号名称本身不决定全网精细度。研究局部电流分布时落实相应空间表示，使用代理读数时限定经验证的条件，不将其视为未求解的局部电流。 |

**先满足必要过程、数据约束与判别能力，再比较成本。** 主体模型承担本轮正式结论，可以直接采用点模型；机制对照用于检验某个作用，表示对照用于检查近似是否保留目标关系；代理或小模型可辅助搜索与成本估计，关键候选和结论回到满足约定要求的主体模型检验。不是每项任务都要构建这三类模型，点模型也不必先与多区室模型竞赛才能成为主体。

混合精细度时写明各群体的职责、实际输入与反馈、观测贡献及近似边界；少量复杂细胞的展示不能代表全网实现了相同机制。简化比较须覆盖本题的输出、机制判断和适用新条件，不以一次胞体拟合或整体相关系数证明所有局部量都被保留。

## 比较表示，再比较实现

1. **用问题寻找独立路线。** 按对象/条件、目标观测、候选过程、数学表示及相关论文引用检索原始研究、补充材料、作者代码和数据；软件名只是入口。优先选少数能改变结论且满足约定机制和观测的路线，再比较可检验的简化，不强凑数量。多篇构建研究的阅读深度按[构建调研](construction-methods.md#深读并比较多篇构建方法)安排。
2. **分别查清四类支持。** 生物/物理研究支持哪些作用关系；模型原文支持哪些方程与近似；官方文档和固定版本代码实现哪些能力；本次组合和条件迁移还需要哪些检查。一篇机制论文不能同时证明软件兼容、参数适用和组合正确。摘要、方法阅读、源码检查、作者示例运行及本项目验证分别记录。
3. **明确软件的实际职责。** 区分模型方程、数值求解、构建编排、交换格式、参数推断/分析和展示；一个软件可承担多项职责，但每项要具体。格式可解析、数组可传递或两工具分别可运行，都不足以证明科学接口成立。优化器不会自动给出可靠后验，拟合的有效连接也不能无依据解释成突触电导。
4. **核对当前采用版本。** 查所需功能、支持的模型子集、接口/数据格式、依赖、平台、许可与维护情况；使用代码时固定版本/提交。软件印象与旧教程不能替代当前能力核查；文档、源码和安装环境不一致时保留差异及影响，不把所有软件都列为已兼容或已验证。
5. **给出有条件的推荐。** 先看是否覆盖必需过程与目标量，再比较数据约束、可复用实现、接口改造、数值检查、总成本及环境可行性，不套统一总分。条件足够时给首选、确有价值的备选及切换条件；无法分辨时保留候选和下一项判别，不编造唯一最佳工具。已有实现适用则保留，不因发现新软件就迁移。

用户明确指定软件、平台或复现对象时尊重该约束；仅提及某软件不等于锁定它。确有能力冲突时具体说明缺失关系、可行范围和代价，按[分轮交流](interview.md)讨论会改变目标的取舍。提问围绕解释层级、观测和允许简化，按所选档位分批讨论并附建议；公开能力由 AI 查，不让用户从长软件清单中猜选。

## 接口决定组合能否成立

在模块原有七项定义中落实[科学接口](mechanism-extension.md#接口只展开实际采用的关系)，不再建第二份接口表。明确交换量的含义/单位/符号、源和接收对象、坐标与取向、面积/体积/数量转换、边界、时间采样与交换、状态更新归属及是否反馈。区分输入、动态状态、计算得到的量和仅供展示的量，避免重复施加已由另一模块产生的作用。

特别检查“设备/场 → 细胞”“细胞/群体 → 观测”“群体 → 细胞”的实际关系。跨模型连接需要依据、转换方程与适用检查；找不到关键关系时，保留有边界的假设、候选或数据缺口，不能用随意倍率连通。方法缺口影响原目标时明确尚未解决，不借简化静默取消目标。

## 何时结束选型并开始计算

当前路线能表达本轮目标，必要输入、参数取值/估计办法、接口、比较和资源已明确，且剩余差别更适合用计算或新数据判断时，即结束本轮选型。它不要求消除全部科学未知；也不要求继续收集所有软件。尚待研究者决定的必要事项按原规则处理，设置齐备后沿用[提问结束提示](interview.md#何时结束提问并进入实施)。

在授权范围内尽早做**输入到主要读数的最小相关计算**，同时完成所用组件、单位、数值与接口检查，再扩展到约定规模。多模块项目不等所有分支达到最高细节才首次连接。只委托调研时交付方法与待执行比较，不自动安装软件、迁移工程或启动仿真。

区分“资料可见、源码可复用、环境可运行、目标示例已运行、原研究已复现、本问题得到检验”，按实际达到的层次报告，不能相互替代。成本沿用[执行管理](execution-management.md)，累计接口开发、迁移、失败尝试、构建、求解和保存，不在换软件后清零预算。场、网格或观测转换等中间结果仅在生成条件与用途仍匹配时复用，按[版本规则](versioning.md#修改后哪些结果仍可使用)处理。

## 写入现有方法和最终正文

不新增项目必填文件。实际搜索仍进 `search_log.md`，来源进 `sources.md`；在 `method_comparison.md` 的同一份比较中保存目标/缺口、候选表示及尺度、实现职责与版本、资料支持和查证深度、接口工作、采用/放弃理由、切换条件及下一项检查。选定路线进入 `model_spec.md`，参数沿用主对应表，实际计算及成本进入原运行记录。

最终正文说明为什么采用这条方法、实际用了什么数学模型和软件、它们各自计算什么，以及如何得到所报告的观测量；对推荐、已实现、已运行和已有实验支持分别表述。网络任务继续报告实际神经元模型、数量、连接和基础活动，不用软件介绍代替科学方法与结果。纯场/稳态等明确委托的任务按实际对象报告，不虚构神经元、发放或物理时间。

十四类、86 条事项及固定编号用于神经模型部分的完整性，七项定义也可描述实际接入的其他模块。它们不是覆盖全部数学/物理方法的分类表；新增必要过程写入适用模块、方法和检查，不重排原清单。现有自动检查的范围按[逐项规则](element-coverage.md)处理，不能通过编造 `model_scope`、`mode` 或 `features` 值宣称支持新类任务。
