# 模型建成后交付什么结果

在拟定记录方案、正式运行与最终交付时使用。目标是让研究者直接判断：实际建成了什么，活动是否符合模型定义，条件差异有多大，结果在哪些检查与数据范围内成立。按目标选择输出，不靠文件或图的数量判断完整性。与[构建方法](construction-methods.md)、[阶段检查](workflow-checks.md)共用数据及记录，不另造一套报告体系。

完整调控实施将[多组合筛选与确认](regulation-design.md#完整实施的最低必需研究)登记为必需科学问题及结果：图组覆盖实际参数组合、B/D0/选择候选的原始比较、搜索和冻结后确认；正文给出完整推荐设置、选择/停止理由、分项改善及未改善/恶化、保护功能与适用范围。无有效者仅报告诊断候选，不称恢复；缺少实算搜索或确认不能将调控研究标为完成。该图组并入下述逐题结果，新种子确认不能替代第 5 项真实生物验证；仅调研/设计/局部检查仍按原范围交付。

交代[所选档位](interview.md#首轮选择三档建模深度)及本轮实际范围：探索/简单示例说明已验证内容与不能支持的生物结论；正式构建沿用下列六项要求，真实数据缺失仍如实列为未完成。精确档报告要求与实际达到的精度/验证范围，不把档位名称作为质量或完成证明。

撰写方法、结果解释与论文式结论前，按[科研写作接入](skill-integrations.md#科研文字怎样衔接)读取并采用 anti-defensive-writing：以实际问题、贡献与结果组织文字，同时保留复现细节、完整数据及影响结论的限制。随后按[统一表达规范](external-skills/clear-writing.md)核对同一份正文、表格、图内文字、图注及网页；科学论述和六项顺序保持一致，语言简化不能省略关键定义、单位、条件与支持范围。

## 最终科研文字怎样组织

### 中途补充不取消完整交付

完整模型一经委托，本轮六项交付持续有效，依据实际任务状态触发，不依赖用户最后是否说“总结”“输出结果”或再次点名技能。参数补充、进度询问、纠错、临时问题、中断恢复及“继续”均不自动缩为局部答复；正式运行结束后继续完成比较、图文和最终答复，不能只回答最后一个问题就结束。若已有完整且同版的交付，再次询问局部内容可直接回答，不重复整篇。模型、数据或主要结论改变后，重查受影响部分并更新同版完整交付。

最终答复由**科研交付块＋必要的补充问题答复**组成。前一块严格按六项顺序，摘要是第一自然段，方法图和公式位于各自部分，每题图与解释就近，一句话局限收束这一块。需要另答的问题在其后单独回答，不能插在六项之间；科研报告本身仍以局限收尾。进行中及时回应状态、纠错或阻断事项，但它们不替代之后的正式交付，也不要求每次进度更新都重复六项。用户明确停止、取消、改任务或只要局部交付时遵从并保存原工作状态；普通附加问题不算取消。

用当前 `review.followup_questions` 暂存需在交付后回答的问题（`id,text`），在 `delivery.followup_answers` 保存同 ID 的答案；已及时解决的状态问题不重复入队。需要新增研究才能回答的事项如实说明尚未研究及下一步，不能挪用旧结果回答新问题。队列只辅助接续，不改变原科学问题与预算。

`delivery.parts` 中的 `report_excerpt/response_excerpt` 保存每项的**完整交付内容，含本项图片、公式与必要说明**，不能只摘一句“已做”。用 `compose_response(delivery, plan)` 依序组装实际 `response_text`，检查器核对组装后的全文；图片和公式须在所属部分，出现在其他地方不能抵消遗漏。核对通过后可用 `review_project.py --project <工程> --checkpoint delivery --response-output <新的项目内文本路径>` 导出准备发送的正文；采用该正文，临时缩写或重组后必须重查。脚本能检查准备的内容，不能接管宿主发送动作或证明实际发送与准备稿一致，主 agent 对最后一次输出负责。

### 六项内容与实际来源

先执行[要求与完成复核](project-checks.md#在阶段转换恢复和交付前执行复核)：实际读取原目标、当前问题、采用版本及本轮必需比较，检查保存报告与拟发送答复中的数值、图组、公式和支持范围。分别报告运行完成、校准满足、独立评价支持、科学问题回答和交付完整；一次程序通过不能代替这五项判断。独立评价不支持仍应完整交代，交付写完也不能称原科学目标已全部达成。

用准备交付的命令在新的输出目录实际重绘关键图，确认可重复执行且不覆盖原结果；只有源码存在不算已经可重绘。最终对话使用当前宿主可显示的绝对本地图片路径，保存报告可使用其自身可解析的相对路径。新增公式或方法解释同时更新构建方法正文，不能只补结果报告。复核发现遗漏时回写现有工程记录并检查受影响内容，不再增建一套补充清单。

文字完成检查同时覆盖最终正文、表格和实际导出的图件，按[输出前检查](external-skills/clear-writing.md#输出前如何检查)对照源数据核对含义、单位与结论强度，再查看显示效果。图内改字、图注或表头变化后重查相关输出；不得因正文已经润色就把图表文字标为已检查。问题和处理并入原图件查看记录及交付复核，程序通过不代表读者能理解或科学含义没有改变。

基于最终实际实现、采用的来源和运行结果，写一份读者无需翻阅源码即可理解的模型说明。**摘要式首段 → 模型与方法图 → 主要公式 → 逐题图文结果 → 真实生物数据对比、验证与迭代说明 → 一句话局限**是完整运行后的六项交付要求；在最终对话与保存正文中分别落实，不能把它们变成只出现在附件中的标题。具体参照差异放在模型与方法部分；必要文件入口、详细检查和后续建议放在最后一句局限之前。表格与图支持正文，不能只交付目录、参数清单或“详见代码”。

**第一自然段按科研摘要写成一段完整文字：**用简短背景引出尚未解决的问题，说明为此实际构建了什么模型（具体神经元形式、关键群体/规模及状态），概括最关键的构建与比较方法，给出主要定量发现及其科学含义。结果优先写对照效应、单位、独立重复与适用不确定性；无需在首段塞入全部参数或每张图，但不能以“运行成功、图件丰富”代替发现。根据实际情况写支持、不支持或未能区分，不预设积极结论；没有独立实测支持时用“在本模型和所测条件下”等准确表述。背景从已核实资料中提炼，不在摘要中新增未经调研的论点。

| 交付顺序 | 必须交代和展示的内容 |
|---|---|
| 1. 摘要式首段 | 一段文字串联背景、科学问题、实际模型与关键构建/比较方法、主要定量结果及意义。直接命名神经元或混合模型，概述关键群体/规模和状态；重要效应给出单位及适用的重复与不确定性，不以运行完成代替科学发现。 |
| 2. 模型与方法图 | 展示[整体架构及关键特点](literature-figures.md#模型全貌与特点的方法图)，解释脑区/群体、模型形式、数量、适用空间、连接/突触、输入—输出、初态与运行方法。明确单神经元和网络的具体参照及来源，说明沿用、修改与简化为何服务于问题；设计差异、预期作用与已检验效果分开。每个面板区分方法示意与由实际对象生成的结构/统计，示意布局不能冒充真实坐标或连接。 |
| 3. 主要公式 | 构建方法文档直接展示实际动力学、突触、连接、输入及主要指标的公式或必要算法，说明生理/数学含义、符号、单位、参数来源及源码对应，补全必要的触发、复位、不应期和初始/边界条件。报告及最终对话给出理解主要结论所需的关键式并引用完整方法；不能只列方程名称或套用未启用模型的公式。 |
| 4. 逐题图文结果 | 每个科学问题对应一组实际结果图，并写清比较设计、主要数值、单位、独立重复、不确定性、科学解释与支持范围。基础活动、构建产物、文献/实测比较、优化前后变化及无改善结果在所属问题或方法检查中呈现；说明哪些解释仍不能区分、与原需求及后题有什么关系，不能把图注或图件列表当成问题回答。 |
| 5. 真实生物数据对比、验证与迭代说明 | 专门解释数据来源、实验条件与模型观测的对应、校准与独立评价的实际用途，以及初始失配、修改依据、实际迭代和采用理由；直接展示最终采用模型与真实数据的对比图及定量差异。有迭代时保留初始模型对照，未达标项和验证范围明确说明；缺少真实数据不能由合成参考代替。细则见[下节](#真实生物数据对比验证与迭代说明)。 |
| 6. 一句话局限 | 最后一段用一句话概括最重要的不足及其限制的结论。影响判断的偏差、替代解释、功能联系和未完成事项已在相应正文说明；不靠最后一句隐藏必需比较缺失，也不将所有未建机制堆成局限清单。 |

每段先给出该部分的具体判断，再说明方法或数值依据及与科学问题的关系；方法写实际采用了什么，理由写为何选择，结果写真正观察到什么。术语首次出现时解释其在本模型中的含义，保留关键数值与单位；不逐行翻译代码，不将调试日志写成科研正文。

涉及开放选型或多类过程时，在方法正文交代“目标需要哪些过程 → 为什么采用该数学表示 → 各软件实际计算什么 → 怎样转换为目标观测”。关键备选及未采用理由简述即可，细节引用原方法比较；已推荐、已实现、已运行及已有实验支持分开写。软件清单不能替代模型方程和接口说明，组件分别可运行不能写成组合已验证。明确委托的纯场、解析等任务按其实际对象和结果组织正文，不补造神经元或发放。

全文保存于现有 `docs/results.md`，完整方程、参数和构建细节仍由 `docs/model_spec.md` 及主参数表维护，按[主要公式规则](construction-methods.md#主要公式与实现对应)保持与最终实现一致。报告和对话中的关键式复用同一公式编号、符号及采用值，可引用完整推导，不能只放方法链接，也不另维护一套参数。方法图在方法文档与结果报告中引用同一正式文件；最终对话也按上述顺序，实际展示主要方法图、各题图组及最终模型与真实生物数据的核心对比图，每组图旁有问题答案、定量依据和解释，再链接完整报告、数据及复算入口。真实数据图已属于某个问题时复用同一图号与文件，在专门说明中给出明确判断，不重复绘制或维护数据。宿主不能内嵌图时提供相邻的图链接与解释，如实说明显示限制，不声称已经展示。篇幅按内容决定，摘要首段不能代替后续方法与结果。

发送最终答复前，用当前运行及[主张支持范围](scientific-constraints.md#交付时按每项主张说明支持范围)核对摘要中的具体模型名称；混合模型同时说清逐细胞部分与群体率/其他部分，不能只在链接的方法中命名。方法图展示决定结果的亚群/路径、直接改动与传播，有调控时标出参考—扰动—作用关系；每题直接指向对应图/面板并解释，必要中间读数服务于机制判断，不为凑图数重复绘制。来源—实际改动—结果的关键关系写在正文，程序检查通过不代替这项解释。

**科研报告及答复中科研交付块的最后一段，用一句话概括当前最影响解释或外推的局限：**具体说明“哪项假设、观测或比较仍缺 → 限制哪一结论”，不写空泛的“仍需进一步研究”，不罗列所有未建机制。影响判断的偏差、替代解释和未完成项仍在相应结果段/图注与详细检查中说明；一句话只是收束，不能隐藏必需结果缺失。运行未结束或必需比较未完成时先如实报告状态，不套用“已全部完成”的摘要。单细胞、静态结构、方案、检查和技能维护按原范围交付，不补造运行结果或额外实验。

在模型概述和相应结果段中回答：实际采用什么点/多区室或混合表示，哪些机制和局部状态真正进入求解，为什么这些细节对本题必要，以及实际比较支持了哪些解释、预测或适用边界。若对复杂度的贡献尚未比较，说明选择依据与待检验部分，不自动称为优势。运行完成、约定生物物理要求满足、数值/实测支持和科学问题回答分别交代；主体点模型不因区室少而降为演示，早期试运行也不因图件齐全而升格为完整研究。保留既有摘要首段、方法图和逐题图组结构，不另加一套复杂度报告。

## 真实生物数据对比、验证与迭代说明

这是完整运行后的固定第 5 项，报告在 `docs/results.md` 设置可直接阅读的专门章节，最终对话给出核心解释和最终模型对比图。使用已有来源表、参数表、运行记录和分析图，不另建重复报告或另一套数据；已在某题展示的图可复用同一图号和面板，但本节仍须交代验证与迭代的实际判断。

| 解释内容 | 正文必须回答什么 |
|---|---|
| 真实数据从哪里来，是否可比 | 指明实验/数据集及版本、对象/脑区/细胞、状态、刺激和记录条件、观测量与独立样本。说明模型输出怎样对应实验读数，统一单位、窗口和聚合定义；尺度或观测类型不同先说明转换和局限，不能直接凭曲线相似判定吻合。 |
| 哪些用于校准，哪些用于验证 | 区分原始实测、实验发表汇总、实验图中提取值，并标明来源位置、提取误差和数据使用历史。参加过拟合、指标选择或候选筛选的数据报告为校准/开发相容性；冻结后未参与选择的真实数据才对应独立评价。更换模拟种子、合成数据或其他模型输出不等于增加真实生物验证。 |
| 为什么迭代，实际怎样迭代 | 连贯说明初始失配、排查结果、修改参数/机制的依据与范围、实际候选/轮次与重复、分项改善和变差、采用/拒绝原因与停止理由。说明哪些偏差仍待诊断、哪项后续工作因数据/预算限制未做；不能只在文件里保留搜索表而在最终对话略去迭代。关键前后值及误差来自同一比较定义；一般模型校准初始已达标而未调参时说明依据，无需编造迭代；完整调控实施仍须多组合筛选和冻结后确认。 |
| 最终模型与真实数据相差多少 | 直接展示最终采用版本的对比图，报告主要指标的实际值、有单位的差异及适用的不确定性。有迭代时保留初始模型对照；不是只展示优化器收敛曲线、参数变化或参考文献原图。 |
| 这些比较支持到什么程度 | 逐条件说明一致、失配、未检验及其对研究问题的影响，区分校准通过、独立评价结果和生物机制解释。对比分析完成与模型达标分别报告；未达标仍展示实际图和差异，不能筛掉失败条件或因此声称机制已证实。 |

**对比图须能直接辨认真实数据与最终采用模型。** 按真实观测选择匹配条件下的响应叠加、分布比较、条件/指标点图或适用的误差面板，不规定每次都画相同图型。实验只有均值和离散程度时展示相应统计；不生成不存在的原始轨迹、个体散点或误差条。不同个体/网络的非配对数据不能逐点相减冒充配对误差；比较应与实际统计设计一致。模拟曲线不得通过未说明的平移、缩放或选择片段制造吻合。

图注注明实验来源、模型版本、观测定义/单位/窗口、真实生物样本与模拟重复各自的数量、数据用于校准还是独立评价、误差条/区间的含义及必要变换。实验差异、模拟随机波动和相容模型集合范围分别表达；用保存的数据与绘图代码复算，正文解释主要数值及剩余偏差。既有数据足够时补分析即可，不为补交付图无故重跑仿真。

**没有可比真实数据时，这项验证仍未完成。** 保存实际检索、缺少的条件/指标及当前只能支持的判断，在报告、最终答复和输出记录中明确标注，不能把仅合成测试或另一模型的结果改称真实数据，也不能降低必需性以宣布完整交付。若原委托明确仅做纯理论、软件验证、方案或技能维护，则按该范围说明不适用，不补造实验；缺少原始记录但存在可比的真实实验汇总时，可以完成相应层级比较，仍不得宣称已验证原始轨迹或独立个体。迭代细则沿用[实验约束校准](calibration.md)，不另增加搜索流程或确认轮次。

## 与常用模型的比较怎样写

“常规模型”不是统一的模型类别。优先从本次已经深读的构建文献、所复现的作者实现或已指定的原版本中选择最相关的参照，注明名称、来源/版本、适用问题和选择理由；资料不足先定向补查。单细胞参照与网络参照可以不同，但各自要明确。参考模型的未知项标为未核实，不把未提及当作没有实现；不把所有其他模型统称为“普通模型”并预设它们均缺少本模型机制。

| 层面 | 具体比较什么 | 怎样解释实际差异 |
|---|---|---|
| 神经元 | 方程与状态、点/多区室表示、放电与复位或通道机制、适应/其他动态机制、参数分布及校准。 | 区分继承模型、不同参数化、机制扩展和另一数学形式。相同 LIF 方程采用不同参数时，准确写成 LIF 的参数化调整；只改连接不能声称提出新神经元模型。 |
| 神经网络 | 群体与规模、空间/形态、拓扑和跨区投射、突触作用、输入相关性、异质性、可塑性与耦合方式。 | 说明这些组织怎样改变可研究的问题或假设；神经元方程不变时，网络仍可有实质差异。目录拆分、换后端或仅绘制三维布局不自动构成网络动力学创新。 |

将比较写成“参照设定 → 本模型实际设定 → 为什么需要这项差异 → 对输出可能/实际有什么影响”。复用方法对照表、参数与实际结构记录，只在正文摘出影响理解的差异和必要的相同项。确无神经元或网络机制改变时直说沿用，说明任务价值在复现、参数估计、问题应用或其他实际完成的内容，不强行制造差异。

**说明差异不等于证明优势。** 来源和实现可支持方程/结构差异；尚未运行的影响写为预期或待检验。声称更准确、更稳定、更快或更能解释某现象时，应有适用的共同协议、观测/指标、对照和实际结果，并保留代价与不利结果。多个要素同时改变而无分离对照时，只能评价整体变化，不能把效应归给其中某一项。不存在通用的“更复杂即更好”。

结构对照、原模型—修改模型比较、实验数据验证各有用途，不能互相替代；新增机制也不自动等于科学创新，创新判断另需相关研究对照。仅为补写说明时，先用已有资料和结果完成可支持的比较；未进行性能对照则如实说明，不自动开展所有常用模型的大规模比较，也不撤掉原任务已经要求的比较。

## 让结果回答明确的科学问题

研究型模型按[问题推敲与迭代](scientific-questions.md)形成核心问题，按需要连接少量子问题。在当前构建方法保存“现象与最近邻研究 → 未知关系及认识增量 → 合理解释与不同预测 → 必需能力和比较 → 判断与主要表图”。每题明确向下一题传递什么，或如实列为并行问题；用户仅委托工程整理、复现或软件检查时按原范围交付。

用户不必在最初请求中已经定题。经[调研与追问](interview.md)形成当前问题后，保存用户原始现象、采用的测量定义、候选选择及改变原因。探索阶段的小模型可回答下一项判别问题；不能把这一局部产物写成最终研究已经完成，或按有利结果重新定义原问题。

最终正文逐题叙述“原未知与比较 → 实际结果和数值 → 能支持什么及范围 → 对后题/后续观察的影响”，引用已有运行、数据和图件。每个已委托问题均交代实际状态：在规定条件下支持/限制某解释、有效比较下仍未能区分，或尚未完成；预算用尽、搜索没找到解、分析不能识别不能单独改称科学边界。校准完成与问题回答分开报告。

**每个科学问题对应一个可辨认的结果图组和一段完整的回答。** 沿用问题标识作为小节或图组标题，先交代问题及比较逻辑，再展示图组，随后用定量结果解释发现、候选解释与支持范围。图组可以是一幅多面板图或若干相邻图；面板数服从问题，小问题可由单幅图充分回答，不机械规定每题图数。共用对照和已有图可交叉引用，不复制数据或为了“一题一组”拆成重复图。

图组通常连接适用的原始响应、各独立单位的汇总/效应和能支持该题判断的比较或检验。每个面板说明在该问题中的作用，图注能独立读懂条件、读数/单位、样本层级与数量、时间窗和误差含义；正文给实际答案，不能只复述横纵轴。文献/实测对照、机制比较和稳健性结果放在其所支持的问题旁；跨题共有的基础活动与实现检查集中展示并引用。方法图用于解释构建，不能充当问题已获支持的结果图。

未能区分或不支持假设的有效比较仍保留图组和相应结论；缺数据或未执行的比较明确写未完成，不生成占位曲线。所有必要结果继续保存，正文围绕科学问题选出足以支持判断的主图，剩余逐步记录与补充图在原报告的相应章节定位。

默认静息态同样可以研究科学问题，例如“在相同背景条件下，哪些连接或细胞动力学差异能够解释群体基础发放率的差异？”这只是问题形式示例，具体机制需调研后选择。候选网络可在相同静息协议下比较，无需自动增加外部刺激、疾病或治疗条件。完成静息态发放率校准与解释该现象的机制分别报告。

| 结果层次 | 应回答的子问题 | 可采用的数据与图件 |
|---|---|---|
| 构建与实现 | 实际模型有哪些对象、规则和机制，它们如何对应问题？ | 神经元模型与参数、数量及适用坐标、连接/突触统计、各构建步骤产物及检查。 |
| 静息活动与异质性 | 网络产生什么基础活动，不同群体和个体有何差异？ | 实际尖峰/状态轨迹、群体率时程、逐细胞分布和静默比例；相关、间隔或频谱指标仅在问题需要且记录足够时加入。 |
| 主要关系与效应 | 所关心因素改变时，目标现象怎样变化、变化多大？ | 按条件/群体/独立单位的效应量、分布、时程和适用的不确定性，保留完整对照。 |
| 机制区分 | 首选解释能否与合理替代解释区分？ | 在范围与预算内开展针对性的机制移除/替换、参数或连接规则对照；写清保持不变与同时改变的量。 |
| 文献与实测评价 | 模型能解释哪些已发表特征和实际观测，偏差在哪里？ | 参考—模型对照、逐条件误差、残差及适用的独立评价；说明数据用途和观测转换。 |
| 优化及结论稳定性 | 调整是否带来改善，结论是否依赖偶然种子或狭窄设定？ | 初始—最终比较、分项误差、参数变化、适用的数值/关键假设比较，保留失败和无改善结果。 |
| 预测与科学结论 | 已有结果支持什么解释，还能怎样进一步区分？ | 从已执行比较推导的定量或方向性预测、适用条件及所需新观察；未计算部分明确标为待检验假设。 |

按科学目标选择上述内容，既覆盖构建过程，也形成连贯的科学结果。不为凑图机械运行所有分析；主要机制问题必须有与结论相称的对照，纯描述性问题则明确描述范围。沿用[文献图学习](literature-figures.md)选择适合的表达，每组主图记录其问题、数据、统计与所支持的结论，重复展示同一均值曲线不增加科学信息。

涉及模型集合或判别设计时，可用预测重叠、条件边界、恢复/混淆及观测方案比较图表达实际认识，先完成[对应比较](run-compare-optimize.md#解释集合与判别能力)。解释新增机制相对简单参照改变了什么、对早先问题有何影响；模拟集合、连接实例、输入重复与生物样本分别报告，集合占比不能无依据解释为机制真实概率。

在运行前固定主要问题、比较与指标。调研或运行中产生的新发现可作为探索结果保留；如据此修改主要问题，更新方案并说明新增检验。不得筛掉不支持假设的条件、按结果挑选主要指标或为得到预期结论调整模型与评价标准。

交付时给出核心问题的实际答案及效应量，区分模型内机制支持、与实验的一致性和仍待检验的预测。多个解释均能说明结果时报告尚不能区分；阴性结果也可回答问题。完成研究流程不保证机制被证实，尚未解决的部分应明确保留，不能把丰富图件、拟合优度或工具检查通过等同于科学问题已解决。

进一步区分未用于选择的模拟条件预测与独立实测支持：新种子或留出模拟不能替代生物验证。已知模拟案例恢复成功只支持相应分析能力；理想机制移除、补回或内部状态解释先限定在模型及操作条件中。未进行的判别或新实验只列建议，不把模型内结果提升为现实中的唯一原因。

**让逐题结果回到原需求。** 除科学答案外，说明相对相应科学参照/当前办法增加了什么，本轮结果会改变哪项认识、测量或选择，模型读数到真实目标还缺什么联系。面向应用时按[用途比较](run-compare-optimize.md#面向具体用途的比较)报告分项效果、代价及排序条件；基础研究说明实际理论或机制贡献即可，不追加空泛的临床展望。

涉及临床用途时，按实际研究设计和目标表述：仿真支持模型内预测或候选，回顾性观测一致与未用于开发的实测预测各有范围；实际用途评价须有相应比较和功能/临床结局。独立预测表现不自动证明改变决策有益，研究被称作“前瞻性”也不单独保证因果或效用结论。登记完成、公开结果、非劣效与优效分别核对，相关研究队列和虚拟样本不能混计。这里是主张与材料对应，不是每个课题必须逐级升级的流程；未来研究需要单列，不能将有临床背景的仿真写成已能指导个体治疗。

## 生物学变化与模型修改依据

涉及环境、疾病、干预或具有生物学解释的机制修改时，**最终报告正文和交付答复均须说明“观察到什么变化、为何可能发生、本模型如何改变、实际产生什么结果”**。报告按[场景调研与修改](scenario-adaptation.md)逐项展开，不把这些内容只留在搜索日志、源码注释或附录链接里。一般参数校准也须说明其约束数据和调整理由，但不把纯数值设置解释成生物学病因。

先用连贯的科研文字解释主要变化及机制依据，再给一张可定位的对应表。同一路径可合并叙述，但所有实质生物学改动应有对应；补充文献很多时将细节放到方法中，正文保留足以理解选择的内容。

| 正文必须回答的问题 | 实际填写要求 |
|---|---|
| 生物学上发生什么 | 指定对象、条件/阶段及对照，写原始测量量、方向、幅度或已知范围，引用具体实验图表/数据；只有定性证据就明确写定性。 |
| 为什么可能发生 | 写支持的作用关系及机制来源，区分直接操纵、关联、模型解释和本项目假设；保留补偿、冲突和无法区分的替代解释。不能把终点拟合当成原因已确定。 |
| 因此怎样修改模型 | 说明选择该入口/表示的理由、作用对象、修改层级、实际前后值/公式与单位、时间协议和来源到参数的转换；关联参数、代码与最终解析配置。不是只写“减弱抑制”。 |
| 哪些后果交给模型计算 | 点明已由机制产生而未再次手动施加的变化；说明重建参考、替换旧近似、共享状态或联合作用的必要处理。 |
| 运行给出了什么判断 | 关联实际运行与图表，报告直接响应/适用中间量和主要终点、匹配对照及不确定性；分别说明实现检查、文献/实测符合程度和机制解释范围。 |

来源中的变化是实验事实还是另一模型的预测，来源参数与本次拟合值，运行前预期与运行后结果，均须明确区分。支持、不支持、无法区分和缺少比较都可以如实报告；不同结果引用真实数据，不能补造机制成功的文字。来源链接放在所支持的判断附近，当前报告中的数值从保存的实际配置和分析表核对。

最终答复概述主要修改的上述关系并链接完整章节，直接写实际神经元模型及主要结果；不能只列文件数、给运行命令或说“详见代码”。只有调研/方案委托时，输出对应方法与待运行状态，不填写虚构的运行结论。

调控研究在上述正文和最终答复中再交代：基础参考与实际扰动损害、调控方法的选择依据、入口到生物作用及目标读数的关系、实际采用协议、同时间未调控对照、改善/未改善及保护功能、停止后观察范围、完整候选的实验先例与差异。按[调控结果规则](regulation-design.md#记录图组与最终文字)区分指标正常化、功能改善、机制恢复和临床结论；病理参数未复原不自动否定补偿性改善。方法图展示三部分及实际作用/时间关系，各科学问题的图组解释损害、恢复范围、机制或参数窗口，不能只给最优点或响应面。内容并入既有方法、逐题结果和来源表，不另写重复报告。

| [Pauli 等，2018](https://doi.org/10.3389/fninf.2018.00046)，脉冲网络复现 | 实现细节、求解设置与模型假设的变化需要分别检查。 | 单列组件、数值与假设比较的结果及范围，不把能复跑等同于机制成立。 |
| [Lazic，2010](https://doi.org/10.1186/1471-2202-11-5)，神经科学中的重复单位 | 相关或嵌套观测不能被当成独立样本扩大样本量。 | 明确网络、试次、细胞或动物的层级，报告配对差异、独立单位数及适用的不确定性。 |

2026-11-23 复核 [Nordlie 等（2009）原文](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1000456)的模型组成与描述组织部分：网络架构、连接及神经元/突触动力学应明确，模型描述、实现与结果分析各有作用。本次据用户要求把最终文字组织为概述、方法、两层具体参照、结果和解释；比较的选取与主张边界属于本技能的实施约定，不将该文解释为所有模型必须证明优于某个通用标准。

同日为摘要、方法图和公式要求复核该文关于方程表示、连接算法、触发/复位及网络示意的相关正文：同名模型不能替代明确数学定义，架构图与文字、方程、参数需相互对应。本技能据此细化方法呈现；摘要首段、逐题图组和一句话结尾是用户要求下的交付约定，不能误称该文规定的固定论文格式。本轮未把文中图的布局或公式作为所有模型通用模板。

样本已保留 5 个网络各 10 次配对重复、连接表、尖峰、代表细胞电压和群体电流，也有解析、复跑及步长检查。主要图集中在群体放电率和恢复时间；实际结构与组件检查缺少集中的图表呈现，干预效应缺少专门的配对差异表，数据的轴与字段说明未统一。该模型本身是非空间简化网络，不能为补全展示而添加虚构的解剖坐标。上述判断仅针对本次指定样本，不授权日后自动读取它。

## 在运行前确定本轮结果

将“研究问题 → 必需结果 → 原始记录 → 分析表 → 图件 → 判断标准”写入当前构建方法。沿用已定条件、独立重复与预算，为目标指标保留足够的刺激前、刺激中和刺激后记录；明确所有细胞还是抽样、记录步长和采样规则。不要运行结束后才发现关键电流、状态或时间窗没有保存。

无特殊要求的网络默认以[静息态与基础发放率](workflow-checks.md#默认静息态与基础发放率)作为必需结果：保留无额外刺激时的背景驱动、自发活动、逐细胞/群体发放率、统计时窗、稳定性及与参考的比较。只研究静息态时无需额外增加刺激实验；有刺激任务时，基础活动与诱发变化分别报告。

在既有 `analysis/output/analysis.json` 中登记按顺序排列的构建步骤、其他结果条目、数据与图的对应。条目按实际要求区分必需与补充，状态使用 `complete`、`pending`、`failed` 或 `not_applicable`；必需结果未完成时不能宣称本轮全部完成。不适用项和未完成项说明理由及影响。阴性结果、未检测到响应和未恢复可以是完整的科学结果，不能因此标作仿真失败或从结果中删除。

同步按[文献图学习与重绘](literature-figures.md)选择相关原图，逐面板核对科学问题、数据和统计，再决定适合本模型的图型与布局。将阅读及改编过程保存在 `docs/research/figure_plan.md` 或已有对应记录中，每张正式图以 `design_ref` 引用；未看清原图或本模型缺记录时保留具体状态，不把参考图当成已有模型结果。

## 明确报告采用的神经元模型

完成构建后，最终答复和结果报告都要直接说明实际采用的神经元模型；不能让用户只能从源码或长篇构建说明中寻找。按实际运行配置、细胞构造函数及启用机制核对以下内容：

- **模型名称与具体形式。** 写清全称/缩写及变体，例如 LIF、AdEx、Izhikevich 或某个明确版本的多区室电导模型；说明点神经元或多区室表示，以及实际启用的适应、阈值等相关机制。模型名称、细胞生物类型与模拟后端分别报告，不能只写“NEURON 模型”“Python 模型”或“兴奋性神经元”。
- **各群体对应。** 分别列出各细胞群采用的模型；共用方程但参数不同、使用不同模型或混合精度时明确区分。群体率模型等不显式模拟单神经元的任务，直接说明实际模型形式，不虚构单细胞动力学。
- **实际规模与运行方式。** 按本次运行列脑区/侧别、群体身份、实际数量及有依据的兴奋/抑制分类；动力学细胞、事件发生器、外部记录回放、固定量或未运行部分分开。非逐细胞表示不虚构等效细胞数。汇总每部分输入来自哪里、输出接到哪里，并引用实际投射和事件/状态记录；生物类型未知时保留未知，不能仅为凑 E/I 比例强行分类。
- **方程与实际参数。** 引用当前构建方法中的方程、状态变量及适用的放电触发/复位规则，给出主要参数及单位、初始化和实际配置位置；详细内容共用既有方法与参数表，不再复制一份易失配的参数文件。
- **依据与实现。** 说明来源论文/公开实现、选择理由、与原模型的改动、适用范围及负责代码。优化后核对最终采用的形式与参数，不能继续沿用初始模型的过时描述。

模型名称/变体和群体对应是[最终科研文字](#最终科研文字怎样组织)中的必需内容，详细表放在[结果报告模板](../assets/results_report.md)的“实际模型与本次运行总览”。概览、方法、结构表与参数表使用同一运行版本；方案中曾计划但未实际运行的区域不能列为本次已完成网络，多个区域的名称也不能代替真实跨区连接。

## 以构建步骤的实际结果为主线

[机制扩展任务](mechanism-extension.md)还需交代继承的网络、增加/替换的状态与方程、参数适配及实际接入位置。沿构建步骤展示局部目标响应、适用的共享状态与数值检查、回接网络后的基础状态和目标结果，再比较原模型与扩展模型、适用文献和实测。报告新增机制改变的解释或预测、未改善结果和仍成立的替代解释；读到源码、源模型已验证、本项目已运行与实测支持分别说明。

**每个实际启用的构建步骤完成后，就保存该步结果。** 在当前结果报告中按流程展示“实际输入 → 方法/代码位置 → 生成结果与数据/图 → 检查及偏差 → 下一步如何使用”。沿用构建方法中的步骤标识，并关联负责模块；不能到最后只放一张漂亮的流程图，而中间产物没有记录。不同步骤可以引用同一数据文件的不同字段，无须每步复制整套模型或轨迹。

| 网络构建步骤 | 该步应看到的实际结果 | 对应图表或检查及后续用途 |
|---|---|---|
| 研究与参数确定 | 选定方法、来源参数转换表、已解析全部覆盖值的配置、关键假设。 | 参数原值与采用值对照及单位/范围检查；下一步实际读取该配置。此处是构建依据，不能标成仿真观测。 |
| 细胞群与数量 | 实际细胞标识、模型类型、群体数量及个体参数。 | 数量与比例表、计划与实际比较；用于位置、连线及记录对象选择。 |
| 空间与形态 | 适用时的真实生成坐标、层次、形态与取向。 | 布局或层次图、范围/密度检查；说明是否进入距离连接、延迟或刺激定位。非空间任务明确不适用。 |
| 细胞模型与状态 | 实际机制、参数、初始状态及目标相关的组件响应。 | 代表性电压/状态轨迹及参考误差；确认所选细胞能进入下一步耦合，不能只贴方程。 |
| 连接伙伴生成 | 每个网络实例的实际有向边或可重建的等价记录。 | 方向矩阵、伙伴数/度分布及适用的距离关系；与来源规则比较，为突触赋值提供对象。 |
| 突触与耦合赋值 | 实际受体/耦合、权重、延迟、接触与作用位置、按需可塑性初值。 | 参数分布、单事件响应和延迟/符号检查；展示它们已进入网络作用。 |
| 输入、初始化与运行设置 | 实际输入对象与事件/波形、条件配对、初值、种子与求解/记录设置。 | 刺激时间图或输入统计、送达与单位检查；对应实际运行配置，不能只放计划刺激。 |
| 组装与试运行 | 组件连接和记录通路、小网络真实输出及计算资源估计。 | 核对输入到达、反馈和输出使用情况；说明是否具备进入正式运行的条件。 |
| 正式运行 | 全部计划条件与重复的完成状态、实际时间范围及原始活动。 | 覆盖表、尖峰/状态轨迹与活动概览；将完整数据交给分析，不隐去失败或未记录项。 |
| 分析与最终比较 | 逐独立单位指标、主要对照效应、图件及解释范围。 | 从保存数据重算，连接到下节的科学结果及数值/实测评价。 |

上述步骤是可调整的网络示例。按后端依赖顺序安排，单细胞、群体模型与静态拓扑任务只保留适用计算，但每个必需步骤都要有实际结果和检查。步骤未执行时写待完成；仅有方法示意图或源码文件不算该步已有结果。已完成的来源记录和组件结果可直接引用。原生对象不宜逐个导出时保留足以恢复对象的数据及实际检查，不增加无用的中间文件。

## 按目标组织结果内容

| 结果内容 | 至少保存和解释什么 | 适用图表与边界 |
|---|---|---|
| 实际构建 | 各群体数量；来源规则与实际生成结构的比较；适用时的坐标、层次、投射数、伙伴/接触数、权重和延迟。 | 群体数量表、方向明确的连接统计矩阵或度/权重分布；空间参与模型时展示真实生成位置。来源概率与实现概率分别标明分母，不能强求随机抽样恰等于期望。 |
| 组件与输入 | 目标相关的单细胞响应、单突触/细胞对幅度与时程、实际刺激送达、初始和平衡时段。 | 适用的电压/电流或状态轨迹、事件与延迟比较、参考值与误差表；已有检查可直接引用，缺原始轨迹时明确仅有摘要。 |
| 网络活动 | 所研究群体在各条件下的活动、代表性原始轨迹及必要的个体差异。 | 脉冲模型优先尖峰图、群体率与逐细胞率分布；无脉冲模型使用对应状态量。注明静默细胞、抽样对象与代表试次的选择规则。 |
| 主要科学比较 | 每个独立单位的指标、完整匹配对照、差异方向与量级、单位及有效/无效样本数。 | 配对点图或差异图和数据表，报告适用的区间或离散程度。群体均值曲线不能替代各独立单位的指标与对照效应。 |
| 可信范围 | 实现、数值、关键假设/参数及可用实测评价的实际结果与未完成项。 | 误差及容差表、适用的步长或参数变化图、实测对照与残差。没有相应数据或计算时明确待完成，不生成占位结果。 |

上述表格用于检查内容覆盖，最终展示以“共用的方法全貌与特点图 + 各科学问题的结果图组”为主，共用基础活动和检查可单列。单细胞、静态拓扑和群体模型按问题删减或替换，不能为了凑齐图组增加无关机制、预算或新实验。已有记录可重分析时先补分析；必须新增记录时说明补算内容及预算，不自动重跑全部模型。

## 指标和统计需要说明到什么程度

用户委托实施的动态模型按[运行—比较—优化规则](run-compare-optimize.md)保留初始与优化后的实际运行、文献/实测参考、分项误差、逐轮调整和重新评价。文献图型的借鉴与文献数值的比较分别完成；参考、初始模型和最终模型的关系要能从表图及原始记录复算。实测或优化是本轮必需结果时，不能为了工具通过将未完成项改成可选。

- 每个主要指标记录定义、算法与代码、单位、时间参考点、时窗、平滑与阈值、分母、独立单位及聚合顺序。分箱起点、中心或终点应与图轴一致；尖峰时间不能与记录网格混用。
- 保存按独立单位的值及配对关系，再汇总。多个试次用于估计同一网络的响应时，不能将网络数乘以试次数当成独立网络数。只有一个独立单位时报告该次结果，不伪造跨网络方差或置信区间。
- 优先报告有单位的效应量与适用的不确定性。标准差、标准误和置信区间名称分开；估计方法及重复层级写清。样本很少时展示全部独立点并说明局限，不为形式完整强行给显著性星号。
- 因干预本身可能改变背景状态，刺激研究应展示各自背景与匹配无刺激条件；需要比较刺激效应时在独立单位内计算相应差异，避免把背景变化全部称为刺激效应。配对设计缺失时使用合适的非配对分析并说明。
- “先对轨迹平均再求恢复时间/峰值”和“先逐单位计算再汇总”是不同的量，应分别命名。恢复、潜伏期等指标说明时间分辨率、窗口造成的影响和观测截止。未恢复、未检测到响应、未记录和计算失败保留不同状态，不能一律填 0 或只删去空值。
- 正常的零放电率属于有效数据；静默细胞是否进入分母由预定定义决定。相关性在无方差序列上不可定义；单细胞间隔指标在事件过少时不可估计，需记录原因。不能用缺失状态掩盖本可计算的零值。

## 数据、图件和说明怎样对应

保留现有 `results/` 原始输出和 `analysis/output/tables/`、`figures/`，不另建一套 final-results。采用[分析记录模板](../assets/analysis_manifest.json)或兼容结构登记以下内容；已有记录只补所缺字段。

1. **运行覆盖。** 原始 `run_id`、实际运行记录、预定条件/协议及独立重复、完成或失败状态。按计划核对完整组合，不能从现有文件反推“计划就是这些”，漏掉条件后仍称完整。
2. **数据字典。** 每个文件/数据集的用途、字段或数组、类型、单位、维度与轴顺序、细胞/群体/试次标识、时间向量及参考点、记录选择和缺失值含义。NPZ/HDF5 原生元数据可以直接引用，不要求另导出巨大 CSV；可读的主要指标表仍需保留。
3. **图件对应。** 每张图的标识、正式文件、所用数据标识及筛选、绘图代码/命令、图注，说明样本层级、误差条、时间窗与代表样本。矩阵明确行列方向；同一变量与条件在各图中保持一致的单位、颜色和命名。
4. **结果说明。** 将[结果报告模板](../assets/results_report.md)填入已有 `docs/results.md`，按[正文主线](#最终科研文字怎样组织)写摘要式首段、模型与方法图、两层参照差异和逐题图文回答，专门给出真实生物数据验证与迭代说明及最终对比图，最后一句概括主局限。数值从实际参数/结构/分析表核对；不手抄另一份会漂移的汇总。
5. **复算与展示。** 从保存数据实际重算主要指标和图件，核对表和图中数值；打开渲染图检查坐标、单位、图例、文字遮挡和缺失状态。主要图保留可编辑矢量格式及需要的预览，图注独立可读。真实生物数据对比图同时登记实验数据、最终采用模型及适用的初始模型数据，说明各自数据用途。图像文件存在不等于已检查显示正确。

结构统计和分析表通过标识引用共享原始数据。实际生成网络的图与机制示意图区分；大型网络只显示抽样边时注明抽样规则。禁止只留截图、只留均值或把所有科学信息埋在未经说明的二进制数组中。

## 可执行的交付检查

[check_outputs.py](../scripts/check_outputs.py)检查本页约定的 `analysis.json`：构建步骤的顺序依赖、输入/输出/检查引用与完成状态，其他必需结果状态、原始运行引用、非空文件、数据/图/代码之间的引用、CSV 字段与数值、主键、计划条件组合及有原因的空值。它只读，不运行模型或绘图，也不评价文献适用性、统计设计、参数来源或生物学正确性。非 CSV 数组内容、图形显示、对照是否充分及计划是否完整必须另行核对，报告会列明这些范围。

```text
python <skill_dir>/scripts/check_outputs.py --project <project> --analysis analysis/output/analysis.json
```

`--output` 可指定项目内已有目录下尚不存在的报告文件，不覆盖已有内容。正式工程依赖该工具时保存所用脚本到 `tests/`，不依赖个人 Skill 路径。详细字段见[输出记录格式](output-manifest.md)，工具行为用[合成测试](../evals/test_check_outputs.py)检查。

交付完成需要同时满足：本轮必需结果齐全、主要数据与图能复算、方法与实际运行相符、已做检查及科学限制准确。必需模型模块、实测数据或预算仍缺时说明具体状态，不因生成了报告和图件就称所有研究目标均已完成。

发送最终答复前，逐项核对上述六项是否在实际图文中落实，并从同一版模型、解析配置及分析表核对摘要数值、方法图、公式、逐题结论及真实数据对比图；明确迭代中实际使用的数据和最终评价是否独立，不能将未验证写成验证通过；单神经元和网络参照须明确，差异及性能措辞须有支持，末句局限不得掩盖正文缺口。只完成仿真而图、公式或解释未完成时，继续完成已委托的交付工作；确有无法完成的部分则准确说明状态。文件检查器不评价这些科研判断，不新增按标题或关键词出现就判定合格的检查。
