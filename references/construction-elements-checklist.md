# 神经网络模型构建要素清单

用于建模方案整理 模型实施与已有模型复用

本清单用于明确一个计算神经科学模型实际采用的构建选择，覆盖研究对象、网络组成、动力学、输入与耦合、运行条件以及实验信号生成。各项内容可直接整理为模型说明、参数表或配置。

通用内容逐项明确；附加机制按研究问题选择。已有模型统一记录来源、版本和本项目修改。暂未采用的内容可注明不适用、固定条件、外部输入或简化表达。

每项完成后，应能回答采用什么、怎样计算、参数与初值是什么、与谁连接，以及产生什么输出。模型的细胞、突触、网络和仿真定义可参考通用模型描述规范。[1]

## 详细事项

以下事项按模型构建内容排列。具体精度由研究问题决定，细胞与群体模型可共用同一套整理方式。

### 01 研究目标与模型边界

- 定义研究问题及希望解释的现象，例如放电响应、网络振荡、空间编码或实验信号变化。

- 确定模型的外部输入、最终输出和主要比较条件，使每项核心输出对应一个研究问题。

- 列出实际参与计算的脑区、细胞群和生理过程；注明用外部输入或简化映射表示的环节。

- 确定观察尺度和时间尺度，包括单细胞、局部回路、跨脑区网络，以及毫秒、秒或更长过程。

- 为各环节选择必要的表达精度，例如点神经元、放电率单元、简化多区室或详细形态模型。

- 明确未模拟的上游活动、区域外投射和外部环境如何作为边界条件进入模型。

记录模型要解释什么、实际计算什么，以及最终用什么输出回答问题。

### 02 生物学背景与参考条件

- 记录研究对象的物种、脑区、亚区或层次，以及相关年龄或发育阶段。

- 明确所用数据对应在体、脑片、培养或其他实验环境，并记录清醒、麻醉、静息或任务状态。

- 记录所选模型依赖的生理条件，例如温度、离子环境和实验液条件。

- 定义基线状态及疾病、环境、药物或刺激条件分别代表什么。

- 说明形态、连接和电生理数据来自哪些实验背景；跨来源复用时记录所作的映射或调整。

- 确定比较对象是某个实验条件下的行为特征、参数范围，还是一组明确的实验记录。

已有模型可统一引用来源和适用条件，并单列本项目的调整。

### 03 计算单元与细胞群组成

- 选择细胞分类层级，例如简化兴奋性与抑制性群体，或具体的细胞亚型。

- 为各细胞群定义数量、比例或密度；采用密度时同时明确对应体积或面积。

- 区分动态神经元、群体单元与外部事件源，分别说明它们的数量和作用。

- 确定同类细胞是否共用参数，以及需要保留哪些细胞间差异。

- 说明仿真规模与目标生物组织的关系，包括完整局部组织、缩小网络或代表性细胞集合。

- 缩小网络时，明确保留密度、连接概率、入度、总输入或其他哪些特征；同步调整相关定义。

细胞数量、输入源数量和生物组织中的群体规模分别记录。

### 04 空间布局 细胞形态与区室结构

- 明确网络空间是否参与计算；需要时定义脑区形状、尺寸、层次、坐标系和不同群体所在区域。

- 选择细胞位置的生成规则，记录细胞方向、最小间距及其他空间约束。

- 确定区域边界的处理方式，例如有限组织边界或抽象网络的周期关系。

- 需要形态时，选择重建形态或简化形态，并记录胞体、轴突和树突的连接关系、长度和直径。

- 需要多区室时，定义区室划分、膜面积、轴向电阻率，以及不同区室的电学属性。[2]

- 明确突触及外部作用的目标位置；需要观测场信号时保留必要的几何和方向信息。

空间位置、细胞形态和电学区室是分别选择的内容。

### 05 神经元动力学与状态变量

- 为每类计算单元指定具体动力学模型及实现来源，而不只记录模型家族名称。

- 列出实际计算的状态变量，例如膜电位、适应变量、门控变量和离子浓度。

- 明确各状态的变化方程，及突触输入、外部输入和区室间作用进入方程的位置。

- 定义动作电位的产生或识别方式；采用阈值模型时明确重置与不应期。

- 采用电导模型时，明确通道组成、门控动力学、反转电位和相关温度处理。

- 采用多区室模型时，明确各区室的动力学与区室间耦合；采用群体模型时说明变量及输入输出函数的含义。

细胞身份、动力学方程、形态区室和数值求解器属于不同维度。HH 类动力学也可用于单区室。[3]

### 06 参数 单位与个体差异

- 记录参数名称、含义、数值、单位，以及适用的细胞群、区室或连接类别。

- 明确总量与单位面积或体积量，例如总电流与电流密度、总电导与电导密度。

- 说明参数采用统一值、实测分布还是其他分布，并记录范围、约束和需要保留的相关性。

- 区分固定参数、条件变量、待估计参数和由其他量计算得到的参数。

- 记录参数来源，包括原始模型、文献、数据估计或建模假设；标明单位换算和必要调整。

- 复用已有参数集时引用其版本或文件，并列出本项目实际修改的参数。

参数、动态状态、初始状态和外部输入分别定义。

### 07 连接结构与网络拓扑

- 列出所有投射的突触前群体、突触后群体及方向。

- 选择明确的连接生成规则，例如固定入度、固定出度、逐对连接概率或已知连接列表。

- 需要空间约束时，说明连接与距离、方向、形态交叠或区域边界的关系。

- 明确自身连接、同一对细胞重复连接、双向连接和特定回路结构的处理。

- 分别定义不同来源细胞的数量、每对细胞的突触接触数量，以及软件中连接边的计数方式。

- 说明拓扑在仿真中保持固定，还是存在结构性变化；缩放网络时同步明确连接规则的调整。

连接伙伴数、接触数和单接触强度分别记录。允许重复边时，入度可能不同于独立来源细胞数。[4]

### 08 突触动力学与可塑性

- 确定化学突触、电突触或抽象耦合的形式，以及电流型或电导型表达。

- 定义受体组成、反转电位或其他作用方向约定，并说明不同受体是否共享同一输入事件。

- 明确突触响应的时间过程及参数，例如上升、衰减时间常数和响应归一化方式。

- 说明权重的物理含义与单位，以及它对应单个接触还是聚合连接。

- 定义传导延迟、作用区室，以及需要时的释放随机性。

- 启用短时程或长时程可塑性时，明确状态变量、更新规则、参数、初值和权重边界。[5]

连接数量变化、单接触强度变化和可塑性变化应对应不同的模型修改。

### 09 背景输入 任务输入与外部刺激

- 定义背景输入来源、均值或事件率、兴奋与抑制成分，以及时间统计特征。

- 明确不同细胞接受独立输入还是共同输入；需要时定义时间和空间相关性。

- 说明位置、速度、感觉线索或其他任务变量如何映射为网络输入。

- 记录外部刺激的波形、幅值定义、频率或频带、起止时间、持续时间和重复方式。

- 明确刺激作用于哪些群体、细胞或区室，以及进入哪项方程或变量。

- 设备端刺激经其他生理或物理过程进入神经网络时，定义转换关系、空间分布、单位和随机波形生成方式。

持续背景驱动、任务输入和干预刺激分别定义，便于控制比较条件。

### 10 特殊生理机制与模块耦合

- 按研究问题选择附加机制，例如钙动力学、离子稳态、代谢、供氧、血流、神经调质、胶质过程或外部物理作用。

- 为每个启用模块定义输入变量、单位、来源、内部状态、初值、方程和参数。

- 写清输出作用于哪个对象，以及进入下游模块的哪项计算。

- 明确单向驱动或反馈关系，并定义细胞级、脑区级和全局量之间的汇总与分配方式。

- 采用不同时间尺度时，确定变量交换间隔、更新顺序和两次交换之间的保持或插值方式。

- 为共同状态指定更新归属；同一物理作用通过约定的变量或方程项参与耦合。

一个模块应能说明输入什么、怎样计算、输出什么，以及输出被谁使用。

### 11 初始状态与实验时间过程

- 为所有动态状态定义初值，包括膜电位、门控、适应、突触状态及启用的生理状态。

- 说明初值统一、随机、来自稳态求解，还是读取已有状态。

- 明确是否需要预运行，以及预运行结束与正式记录开始的时间。

- 定义基线、扰动、刺激、恢复等阶段的顺序和持续时间。

- 确定条件之间分别初始化、从共同状态分支，还是在同一仿真中连续经历变化。

- 需要表示天级或其他长期状态时，说明标签对应一套状态参数，还是由长期适应方程演化得到。

模型参数相同，也应说明实验是否继承此前的状态和输入历史。

### 12 数值求解 随机过程与运行设置

- 确定仿真器、求解方法及依赖版本，记录自定义机制或代码的具体实现。

- 设置固定步长或自适应误差容限；多区室模型同时定义空间离散。

- 分别设置求解步长、模块交换间隔、记录间隔和总模拟时长。

- 识别位置、连接、参数、输入和释放等随机过程，并明确各自的控制方式。

- 确定条件间配对的随机设置，以及独立重复之间改变的随机实例；记录随机种子或等价的复现信息。[7]

- 根据模型规模确定进程、线程、内存和记录范围；保存必要的配置、实现版本与原始结果。

- 需要中断后继续运行时，定义要保存的完整状态和恢复方式。

重复计算同一确定实例属于复现；独立重复应对应不同的随机实例或其他明确变化。

### 13 原始记录与实验信号生成

- 确定需要保存的事件和内部变量，以及对应的细胞、区室、时间范围和采样间隔。

- 明确从原始记录计算放电率、同步性、调谐或其他派生量的方法。

- 目标为 LFP、EEG、MEG、钙信号等实验观测时，给出内部活动到观测信号的计算关系。

- 对电场信号，定义所用电流源或偶极、空间位置与方向、电极或传感器位置、介质模型和参考方式。[6]

- 记录信号单位、尺度对应，以及滤波、重采样、参考变换和归一化步骤。

- 确保最终指标能关联到具体原始记录及其生成条件。

内部变量、直接派生指标和实验观测信号分层定义。

### 14 分析指标 条件比较与完成标准

- 选择直接回答研究问题的核心指标，给出计算定义、时间窗和汇总方式。

- 为每个比较条件列出改变的内容及共同设置。

- 明确每个数据点和误差范围代表细胞、试次、网络实例、参数实例还是配对仿真组。

- 记录参数设定或拟合数据与后续比较数据的用途；按实际数据来源描述比较依据。

- 事先确定模型完成所需的核心行为、参考范围或误差要求，并说明采用这些要求的理由。

- 需要调参时，限定可调整参数、搜索范围、累计计算预算；按多组参数组合实际运行并逐组检验，主要指标未满足文献与真实数据要求时继续换组运行，直到满足，不因预算批次或阴性结果提前停止。

- 结果偏离目标时，优先定位具体输入、方程、连接、参数或观测环节，再决定下一次修改。

完成标准围绕当前研究问题设置，附加机制与分析按实际需要展开。

## 通用内容与按需内容

| **类别** | **使用方式** |
| --- | --- |
| 通用定义 | 目标与边界、计算单元、动力学、参数、连接、输入、初值、运行、记录和比较均需明确。 |
| 空间与细胞细节 | 真实三维布局、详细形态、多区室和具体通道，按空间作用与研究机制展开。 |
| 附加生理过程 | 离子稳态、代谢、供氧、血流、胶质或外部物理机制，按研究问题启用。 |
| 观测与可塑性 | 实验信号正向模型、突触可塑性及结构变化，根据目标输出和研究时间尺度选择。 |

## 模块统一填写表

每个实际启用的模块可使用同一格式。复用模块填写原模型来源、版本及修改；新模块填写方程与接口。

| **字段** | **填写内容** | **本项目记录** |
| --- | --- | --- |
| 功能与对象 | 表示什么过程，作用于哪些群体、细胞或脑区。 |  |
| 输入 | 变量名称、单位、来源及作用对象。 |  |
| 方程与实现 | 采用的方程、模型名称、代码或文件来源。 |  |
| 参数 | 取值、单位、分布、来源及允许改变的范围。 |  |
| 状态与初值 | 动态状态、初值及状态更新的归属。 |  |
| 输出与连接 | 输出变量、单位、接收模块及进入的计算位置。 |  |
| 时间设置 | 求解或更新时间、变量交换与记录间隔。 |  |
