# 科学问题的推敲、连接与模型迭代

研究选题、已有模型需要深化，或运行发现新的解释缺口时使用。把“值得回答什么”和“模型需要什么能力”共同推进，嵌入原有调研、方法、计算和交付；不增加另一套总流程。只复现、整理、维护或回答单个明确问题时沿用用户范围，不强行扩成新课题。具体方法与软件选择交给[方法发现](method-discovery.md)，交流节奏交给[分轮讨论](interview.md)，实际发问按[问题与选项说明](interview.md#问题和选项要让用户一次读懂)展开背景、取舍与影响，不将下表的主题短句直接用作无解释选项。

研究主线可包含相互衔接的 2–3 个科学问题，但数量由独立认识增量与可执行性决定；一个问题足够时不补题。**科学子问题与交流题数分开**：新建任务的阶段讨论在原构建题数之外通常另加 2–3 个科学讨论问题，按[两类交流规则](interview.md#构建讨论与额外的科学讨论)执行；这些提问用于完善当前研究设计，不要求每轮新增或更换课题。前期问题可以暂定，关键小比较也可用于收敛问题；已有目标和授权持续有效。

## 将科学问题纳入阶段讨论

完整调控实施至少保留[参数组合筛选问题](regulation-design.md#完整实施的最低必需研究)：在固定负面模型和真实可控范围内，哪组设置改善预定结果并满足保护/负担约束；它需要实际多组合运行和冻结后确认，不能由一般机制讨论或一次经验参数示例替代。与已有 Q 编号衔接，额外机制、持续性等问题按价值选择；仅调研、设计和局部检查保持原范围。这个科学必需问题不增加另一套固定问卷，沿用当前三档或继续优化的交流节奏。

需要研究方法辅助时，按[选题职责到模型设计的交接](open-source-reuse.md#科学问题怎样传给模型设计)采用已核对的局部方法。科学问题职责使用问题选择与假说方法，交回可测预测和判别比较；方法/实现职责检查是否能落实，独立复核检查来源、反对结果和解释范围。继续使用本页问题与 Q 编号，不另起一套候选状态。

科学讨论贯穿研究，不能全部压缩到初次选题或最后解释结果。AI 先从资料和当前输出提出有依据的候选，再询问研究者的优先级、可检验条件与愿意解决的未知；不是请用户凭空出题、认定某种机制真实或保证创新。新建阶段通常额外讨论 2–3 项；完成后开放式优化将两类讨论纳入总计 5–7 问，选择尚未明确且能改变研究的问题；以下是主题导航，不是逐项执行的固定问卷。

| 阶段或发现 | 可以讨论的科学取舍 | 回答要落实到哪里 |
|---|---|---|
| 理解需求与首轮文献比较 | 最需要解释或预测哪种现象？最近邻研究仍留下哪些不同解释，本轮优先解决哪个？ | 当前科学问题、价值与范围；新颖性判断由 AI 查证，用户选择优先级。 |
| 构建方法与比较设计 | 哪些候选会对可测结果作出不同预测？优先用什么条件区分它们，什么结果会使当前解释需要修改？ | 假设/预测、对照、预先确定的主要读数和解释分支；不把期望方向写成合格条件。 |
| 小规模构建和试运行 | 新输出对应未解释的现象，还是结构设定的直接后果？下一次比较优先排除哪种替代解释？ | 针对性消融、协议或观测；AI 先排除实现错误，不让用户裁决数值正确性。 |
| 正式运行与真实数据比较 | 当前结果支持到什么层次？存在多种相容解释时，补哪种可得观测最可能改变判断？ | 各题的结论范围、未用条件预测或判别比较；已用结果形成的新假设注明探索来源。 |
| 结果解释与新一轮优化 | 已完成结果之后，最值得获得的新认识是什么？优先降低误差、区分机制、研究失效边界还是检验可迁移性，依据是什么？ | 本轮认识增量、对应图组、实际比较和停止条件；交付已明确时直接交付，不为配额拖延。 |

这些答案需要改变实际方法、比较、数据用途或最终逐题解释，不能只追加一段“科学意义”。沿用既定主要指标和原始问题，新方向保留其形成原因；机制未分清或有效阴性结果不靠重新选指标消失。完成后的开放式改进按[继续优化入口](interview.md#完成模型后继续优化)先研究方向，再按总计 5–7 个问题覆盖科学讨论与构建取舍。

## 从现实需求定位本轮用途

研究型委托先研究具体对象、实际困难、现有办法的不足和未解决关系，再形成问题；涉及健康或疾病时具体核查相关临床需求，不能从现有代码能画哪些图反推一个疾病课题。已有模型的能力用于检验可行性和确定必要增量，不作为选题边界。基础理论、教学或明确复现保持其用途，不编造临床意义。

提出或深化问题时，先从已有资料明确“谁/什么对象，在什么情境遇到什么困难，当前怎样处理，本轮研究希望改变哪项认识、测量或选择”。用原始研究和实际流程查证困难及现有办法；疾病负担或参数敏感性不能单独构成具体研究切口。用途评价按已明确的研究目标展开，基础理论、机制解释、方法研究及复现不必补造患者需求或临床终点。

把以下内容融入当前 `model_spec.md` 的研究目标，已有记录直接引用，不新建需求卡或整套问卷：

| 需要连起来的内容 | 对研究设计的作用 |
|---|---|
| 对象、情境、实际困难及依据，当前可行做法 | 定位具体未知及最接近的参照；区分使用者的操作需要与研究对象/患者的功能、体验和负担。 |
| 本轮用途与贡献 | 明确优先解释、预测、测量设计、候选策略或其他已定目标；不同答案应改变什么，什么属于后续研究。 |
| 当时可得信息、可行选择、时间与资源 | 限定输入、观察窗口、允许操作及实施成本；公开技术事实由 AI 查，未核实的本地条件保留为假设，必要取舍分轮讨论。 |
| 模型读数到实际目标的联系 | 区分内部状态、可测信号与功能/临床结局，说明已有转换依据和缺口；按[场景规则](scenario-adaptation.md#把依据落实到直接改动)核对行动端，按[用途比较](run-compare-optimize.md#面向具体用途的比较)核对评价端。 |

现实重要性、科学新意、计算增益、证据可达性及获得有效判断的成本分别说明，不合成缺乏依据的统一分数。先判断困难主要来自机制未知、测量不足、协议或实际实施条件，再确定模型增量；当前做法或简单规则已足够时，模型研究仍需说明能增加何种认识。公开资料可启动研究，具体场景尚待核实不等于必须等待全部未来数据；但不能把假设的用途需求写成已确认事实。

从需求向下确定问题和必需能力，再从实际结果向上说明贡献。缺少行动、观测或结局联系时，明确本轮可支持的层次及尚缺内容；原来要求的目标保留，改变用途沿用既有取舍规则，不能以改名实现“全部完成”。现实意义也可以是找出有价值的测量、减少无效比较或界定已有方法的适用范围，不必每轮产生干预方案。

## 从文献和实际能力的交汇处找问题

从当前现象、资料与研究意图出发，区分已知观察、作者解释、可共存因素、竞争主张和待解决关系。只有用户指定复用或审查模型时才读取其代码、配置和实际输出；核对真正演化的状态、可操纵入口、反馈、已存记录、观测转换与成本。标签、计划模块和示意箭头不能作为已实现能力；无当前实现时给条件性方案。

检索将现实困难、当前做法、机制解释与数据可用性交叉推进；优先围绕解释不唯一、条件相关的冲突、系统性偏差、测量限制及近似失效。以“对象/条件—关系或机制—操纵—读数”查最相近的原始研究、后续工作、补充方法、数据和代码；先核对看似冲突的实验是否可比。论文未来工作仅作线索，换脑区、换软件或搜索暂未找到都不单独证明创新。已知规律可用于复现或检查，不等待需求或机制被“全部调研完”才进入有价值的比较。

在现有 `method_comparison.md` 或当前方法中记录候选、最近邻研究实际做到什么、本题尚需解决什么、计算能增加何种控制/观测/推理，以及最强反对意见和保留/改写/暂缓理由。认识增量可以是机制解释、未用条件预测、适用边界、观测设计或有依据的约化；理论问题不必硬造“实验无法完成”的理由，也不把基础率或图数当成深度指标。

## 把问题推敲到能够改变判断

先形成少数实质候选，再用下列问题检查并修订；公开事实由 AI 查证，不把整张表交给用户填写，不计算统一的科研价值总分。

| 检查重点 | 应明确什么 |
|---|---|
| 未知与价值 | 未解释的是哪种关系，它是否造成所关注的困难，回答会改变谁的哪项认识、预测或研究决定？与最近邻工作及当前可行办法差在哪里，哪些差异仍待核实？ |
| 合理的不同答案 | 有哪些有依据的竞争解释、定量关系或理论边界？因素可能共存时说明交互或作用分担，不强造互斥假说。 |
| 实验与计算各能区分什么 | 实验为何难以直接区分候选：操纵、观测、时间尺度、混杂或样本限制是否有资料支持？计算增加哪种受控比较、隐藏过程的有条件解释或可测预测？实验本可回答时如实说明计算的实际增量，不夸大其不可替代性。 |
| 是否把答案写进了模型 | 预期结果是输入/映射定义、参数设定的直接重述，还是待计算并可比较的关系？根据预设疾病倍率得到相应变化不能独自证明病因。 |
| 什么结果能改变判断 | 哪个对照、状态、时间窗和当时可得读数能区分候选或改变相关选择？相反结果、共同失败或预测重叠各说明什么？隐藏状态可辅助解释，实际用途须有可测对应。 |
| 最关键的未定前提 | 哪项机制、数据、观测或实现假设一旦不成立，就会使本轮比较失去意义？先做能检验它的最小相关调查或计算，区分技术失败和科学结果。 |

模型若仅定义 `y=F(x;θ)`，相同输入、参数、初态和随机实现产生相同输出首先是定义所决定的结果。要研究相同观测条件下的差异，先判断是否已有可独立变化且有依据的状态、路径或条件；不能为得到目标结论随意加一个隐藏量。浅显的初始问题可以深化，但未经资料支持的复杂表述仍不是成熟选题。

问题已有明确对象、未知关系、可比较答案、关键比较及执行范围时，结束本轮构思，按既有授权进入计算；其余科学未知可以成为研究内容。只调研时交付方案；不为让措辞更深而无限改写，不要求整个未来课题都确定后才能研究第一问。

判断研究深度时分别回答：关键过程是否实际实现，比较是否具有判别力，结论是否受到数据和计算支持，相对最近邻工作增加的认识是否重要。前一项成立不自动使后一项成立；升级模型名称、增加形态或降低拟合误差都不能独自证明创新。期刊质量要求可作为研究参照，不转成统一复杂度等级、固定机制数或录用承诺。充分比较后的阴性结果也可能有价值，未完成计算或有限搜索失败则不能包装为否定性发现。

## 让前一问真正改变后一问

一种可选组织是“相容解释 → 条件规律或失效边界 → 可实施的测量、预测或候选策略比较”，各题回到同一需求。它不是所有项目必须采用的三步题目，也不预设特定脑区、机制、刺激或治疗。

| 子问题示例 | 本问的认识增量 | 传给下一问的实际内容 |
|---|---|---|
| 哪些解释与当前观测相容？ | 明确候选范围内能够约束什么、仍允许什么 | 符合预定约束的机制/参数集合及其关联，或共同不符之处。 |
| 这些解释何时分歧，边界由什么决定？ | 定位条件关系、稳健预测或近似的适用范围 | 有区分力的状态/协议、关键变量或响应边界。 |
| 哪种可实施观测、预测或候选策略对本轮用途更有价值？ | 将模型差异用于可检验预测、测量选择或有条件策略比较 | 具体读数/方案、效果与代价、尚存不确定性和后续检验。 |

对于已委托的扰动后调控，可按“损害在何种可实现作用下改善 → 什么机制和状态决定改善或失败 → 哪种参数窗口/可测选择规则更稳健”组织相互关联的问题，具体依赖随研究确定。按[调控设计](regulation-design.md)分别建立匹配比较、机制判别和候选评价；基础模型及扰动校准是必要准备，不自动各算一个科学发现，也不强制增加第三问或闭环。

逐项说明上一问交付的对象怎样约束下一问的候选、参数、协议或解释。删去前问、或把前问答案换成相反/未能区分，后问完全不变时，两问可能是并行关系，应如实组织。每问要有自己的价值，不把校准步骤包装成独立科学发现。

保留不同结果下的推进方式：某候选受限时检查其新条件预测；多个候选相容时寻找分歧或共同成立的规律；全部不符时先查共同遗漏、观测和协议；关键计算未完成则保留未决，不能写成科学不可辨识。后问不以首选解释必须成功为前提，也不自动执行所有分支。

**机制判别与功能改善分别定目标。** 最大响应、最小误差或最显著变化不自动产生最多信息；最能区分机制的条件也不一定改善功能。若两者都研究，明确主次、约束和权衡。默认静息任务先比较允许的被动观测；诊断刺激或干预只在目标和授权包含时加入。

机制未唯一确定时仍可研究本轮用途：相容解释若支持相同选择，检查这种一致性在相关不确定性下是否保持；若选择翻转，优先找能改变该判断的观测；共同失败则回查共用假设和映射。按[用途比较](run-compare-optimize.md#面向具体用途的比较)执行，不把全部机制识别作为每个后题的前置条件，也不将候选一致当作现实有效性的证明。

## 按能力缺口选择本轮增量

先按[运行诊断](run-compare-optimize.md#优化触发与分层调整)排除方程、单位、输入、观测处理及数值错误。输出不够深入或多个解释仍成立时，再判断下面哪种差距影响当前问题，不自动调参或增加机制。

| 实际缺口 | 本轮优先工作 | 修改范围与检查 |
|---|---|---|
| 分析或记录 | 已有原始记录可回答新问题时重分析；缺变量/分辨率才补记录与相应运行 | 核对数据是否覆盖所需读数及其用途，不推造缺失状态。 |
| 比较协议 | 现有模型能表达差别，但尚无合适条件、时间历史或对照 | 设计可区分预测的有限比较，保持或明确改变的因素；本轮范围外刺激不自动增加。 |
| 数学表示或机制 | 问题依赖尚不存在的状态、反馈、空间或作用关系 | 按[方法发现](method-discovery.md)和[机制接入](mechanism-extension.md)研究最小必要改变及简单参照。 |
| 数据约束或识别 | 多组参数/结构仍相容，现有观测不足 | 保留适用集合，检查估计/判别能力，优先找会改变判断的观测；不靠更复杂算法宣称唯一解。 |
| 行动、观测或目标映射 | 内部量尚不能表示实际作用、可测信号或所需功能 | 先查并补必要转换/测量过程；缺结局依据时报告已有层次与原目标缺口，不自动增加机制或改称临床收益。 |

本轮方法简述“对应问题—已有结果与缺口—最小增量—保持/改变的条件—关键比较—可能结论—预算与停止条件”。新增机制要有来源、参数约束及预期判别用途，按实际比较评价；未实施或比较无效只能说尚未评价，不能断言没有贡献。减少复杂度同样可以是研究推进，但目标依赖或用户指定的机制不能据此擅自取消。

校准、解释比较和预测评价分开，具体模型集合、恢复检查和观测设计见[研究比较规则](run-compare-optimize.md#解释集合与判别能力)。按[修改影响](versioning.md#修改后哪些结果仍可使用)回查受影响的前题；新一问改善而早先约束失效时报告取舍或返回修订，不以新指标覆盖旧失败。无影响的计算复用其原版本，不每轮重跑全部。

每轮以排除某解释、约束预测、发现条件边界、提出更有效观测、形成有依据的候选比较或保留用途结论的简化等收获说明价值。拟合改善与新模块不能替代这些判断；复杂表示未改变目标判断时，可以研究约简，但先比较其预测、适用范围与代价，不能只按当前一个指标删去必需机制。回答已定问题即可收束；预算结束、关键资料不足或比较无效属于本轮停下但尚未解决。继续需说明下一项工作能改变哪项决定，累计预算不重置。

## 一处维护问题，按问题交付结果

优先将需求、本轮用途、问题及依赖写入现有 `docs/model_spec.md` 的研究目标，沿用[构建模板](../assets/construction_plan.md)。可用稳定的 `Q1` 等文字标识，把来源/最近邻、假设与预测、实际能力、协议和完成判断连起来；已有同职责文档直接引用。检索、参数、进度和运行继续各用现有记录，不再新增用途报告。

问题标识仅用于关联现有要求、模块、步骤、运行、数据和图件，不擅增工具未支持的 JSON 字段、模式或成功标签。最终 `docs/results.md` 用摘要概括发现，在模型与方法图说明后逐题配结果图组并回答，记录实际比较、效应与不确定性、结论范围、传给后题的内容及未完成项，按[结果规范](result-delivery.md#让结果回答明确的科学问题)执行。一个结果可以被多题引用，不复制原始数据；共用的方法图不能替代每题实际结果。

改题时保存原问题、触发资料或结果、改变原因及受影响比较。用于形成当前假设或选择问题的响应纳入开发用途，不能回称该假设的独立检验；新问题单列探索来源。阴性结果与有效的未能区分可以有价值，前提是检查和比较有相应能力。文件齐全、预算结束或基础发放率合格，不能自动标记科学问题已经回答。
