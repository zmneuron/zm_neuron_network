# 按科学问题选择并接入机制

用于补充、替换或简化神经元、突触及局部环境机制，也用于新建模型中的相应选择。问题尚未明确时先按[调研与追问](interview.md)形成可比较的目标。原清单十四类、86 条事项继续组织工作；不另建一套全领域清单，不因参考资料涉及某种系统就自动加入它。

机制用于某种环境、疾病或干预时，先按[生物学变化与原因依据](scenario-adaptation.md#先查发生什么再查为什么)建立修改理由。本页负责方程与接口；相应的扩展参考、连续状态和实验对照按[场景细则](scenario-adaptation.md#参考模型与连续历史)接入现有工作，不要求每次机制修订额外开展疾病研究。

## 先判断缺少的是机制还是条件

从用户指定模型的实际方程、输入、初态与观测出发，说明它已能表达什么、哪种目标量或干预尚无法表达。偏差可能来自协议、初始化、数据处理或实现错误，先核对这些相关条件。用户未指定复用工程时，从本次新建方案判断，不扫描历史模型。

缺少的若是场、运输、观测或其他整类过程，先按[方法发现](method-discovery.md)比较必要表示与实现，不只在现有神经元目录中调参。该环节并入当前调研；方法选择已有依据后再按本页接入具体机制。

分别决定：**采用什么机制、需要什么表示、复用什么实现**。保留仍适用的细胞身份、群体、连接与实验设置；目标确实依赖新的树突位置、共享介质或反馈时，修改受影响结构。不能为“保持骨架”而把必需空间或相互作用塞进不相容的局部参数。

比较候选后、首次接入前及网络回接出现新差异时，按[分轮交流](interview.md)讨论当前尚未明确的 2–3 项研究取舍，例如目标解释层级、允许简化、优先读数和可用材料。不是每个函数都问一次，也不是确定初始机制后便停止讨论。选型所需小运行与正式记录的区别见[执行深度](workflow-checks.md#探索小运行与正式构建)。

| 当前表示与目标差异 | 优先考虑的改动 | 需要保留的解释范围 |
|---|---|---|
| 有效点模型需要适应、动态阈值或更好的脉冲预测 | 比较适用的有效状态与复位规则，如 GLIF 候选 | 有效适应变量不自动对应某种离子通道密度。 |
| 有效点模型要研究离子特异电流、泵或能量过程 | 对目标细胞采用相应电导/浓度表示，或建立有依据的有效映射 | 总输入电流不能仅改名为 Na、K 或 Ca 电流；新增电学表示需重新核对目标响应。 |
| 单区室电导模型需要通道、钙或调质过程 | 增加或替换相应状态和作用关系 | 核对已有机制是否已承担同一电流、浓度更新或调节。 |
| 目标依赖局部树突电压、钙或输入位置 | 引入足够的区室与空间表示，比较必要的简化和详细方案 | 单区室电压、显示坐标不能代替局部量。 |
| 多区室网络需要局部机制 | 在指定细胞、区段或突触中接入 | 沿用适用形态和身份，实际记录接入位置与目标输入。 |
| 涉及共享介质、可变体积/膜电容或强反馈 | 建立最小耦合系统，明确共同状态与求解关系 | 两套机制不能各自独立更新同一个物理状态并重复计入作用。 |
| 希望简化、约化或以代理替换昂贵模块 | 明确保留量、输入范围、近似条件及误差，再比较目标结果与成本 | 代理隐状态不直接解释为生理量；可微机制求解、代理和任务网络分别说明。 |

这些是选择提示，不是默认采用的模型目录。公开入口见[机制文献与代码](mechanism-sources.md)；未收录的机制继续从现象、原始研究和作者实现发现。

## 从论文和代码提取可接入的最小单元

对准备采用的机制填写[机制接入说明](../assets/mechanism_plan.md)。小改动可合并到 `docs/model_spec.md`；有独立来源和适配过程时放 `docs/research/mechanisms/<mechanism_id>.md`，由当前方法引用。仅被筛选的候选留在原有 `method_comparison.md`，不为每篇论文另建卡片。

集中核对与本次选择相关的原始方法、补充材料、勘误和代码。按实际缺口比较独立候选，不机械重做完整网络调研。每份资料说明它帮助决定了什么，区分读取摘要、方法、源码、实际执行和本项目检查的深度。

代码记录至少定位到对应论文、提交/归档版本、文件和函数/机制、实际状态方程、输入与初始化、参数组合及相关运行入口。区分作者实现、社区再实现、后续移植和教学例子；平台支持一种接口不代表提供了目标生理机制。论文、代码默认值和出图版本不一致时保留差异，不能混成一套未经说明的参数。直接复用源码时检查该版本所需依赖与许可，未查明的状态如实记录。

没有公开代码时，依据方程与协议作“本项目再实现”，检查相应行为；没有成熟机制时，可提出范围明确的有效模型或假设，保留其依据、待约束参数和能够否定它的观察。局部模型的新组合需要验证新增耦合，组件分别发表不代表组合已得到实测支持。缺少必要定义时完成可行分支并列明缺口，不把示例数值转成正式生理参数。

## 参数和状态一起适配

沿用同一份[参数对应表](construction-methods.md#把来源数值对应到本模型参数)，机制说明引用 `parameter_id`，不重复维护数值。先确定方程与含义，再提取参数。保留共同拟合或共同标定的参数组合，不能逐项跨论文拼接后默认相容。

- 核对物种、细胞、年龄、温度、制备、溶液和输入协议；跨条件迁移区分可借用的机制结构与需要重新估计的数值。温度修正采用有依据的关系，不统一套用一个系数。
- 区分总电流/电导、密度、单通道或单接触量，写明面积、体积、归一化和符号转换。化学总量、浓度、通量与浓度变化率按所在域和几何转换；可变体积时处理相应的浓度变化，不能沿用固定体积公式。
- 逐个说明新增或改变的量是固定参数、外部驱动、动态状态、代数量、待估参数还是派生观测。固定浓度变成动态状态时，同步改变初始化、更新规则和反转电位等依赖项，避免旧常数仍在覆盖新状态。
- 有效钙、游离钙、总钙和荧光信号分别定义。观测映射引用测量条件，不能用同名变量直接连接。
- 慢变量、储库、离子及适应状态给出初态、预运行或条件化参数的依据。阶段标签不能替代实际的状态历史；只比较静态作用与研究起效/恢复时程需要不同表示。

## 接口只展开实际采用的关系

将下面信息写入现有模块七项定义及机制说明。模块之间的突触、电流、反应、物质运输、场作用、调节和观测映射分别描述，不能统称一个没有量纲含义的权重。

| 接口内容 | 必须能回答的问题 |
|---|---|
| 交换量与位置 | 传递的具体量、单位、所属细胞/区室/组织、状态/通量/事件角色是什么？ |
| 关系与方向 | 是实测输入、规定函数、上游模型单向输出，还是实际求解的双向反馈？新组合是否超出原论文范围？ |
| 映射与范围 | 映射方程与依据是什么，涉及哪些面积、体积、边界、坐标系及取向？如何换算、聚合或分配？缩减细胞数代表更小组织还是代表性抽样，总量是否重复乘以细胞数？ |
| 共享状态与过程 | 谁负责更新电压、浓度、反转电位等量，其他模块如何读取或贡献通量？泵的物质、电荷和能量作用是否来自一致定义，是否重复计入？ |
| 时间与数值 | 积分步长、模块交换间隔、记录间隔分别是多少？连续量用保持、插值还是积分量，事件如何转换？生理延迟与数值交换延迟如何区分？ |
| 观测与反馈 | 量只用于作图/测量，还是回到动力学？对应观测几何、处理步骤与实际反馈路径是什么？ |

强反馈可统一求解或采用有依据的数值耦合，不要求每个模块独立进程。以相关输入和目标量检查交换间隔/求解精度及适用的守恒关系。器官、胶质、代谢、外场、身体环境或群体模型仅在本轮问题涉及时展开；仅有规定供氧、光强或活动输入时，不宣称已经构建自主闭环。

外场到细胞作用、内部活动到实验信号均需要具体转换关系，不能把场强直接当膜电流或把发放率改名为测量信号。几何、场解及观测转换的复用须核对生成条件和当前用途；接口只返回成功或数组维度相同不能代替科学与数值检查。

## 最小相关单元运行后尽早回接网络

在预算内确定原模型、扩展模型以及确有判别意义的机制关闭/替换或其他候选。能配对时沿用同一输入和随机配置，说明为匹配工作状态而同时调整了哪些量。原模型结果与扩展后结果分别保存，不覆盖原始运行。

| 阶段 | 适用检查与产物 |
|---|---|
| 来源或局部单元 | 运行与目标相关的作者示例或本项目协议；保存状态、电流/通量、输入输出与目标响应，核对方程翻译、单位、初始化和事件。只读过代码时不称已复现。 |
| 最小耦合系统 | 共享状态或强反馈尽早共同运行，检查作用方向、更新归属、边界和目标相关数值误差；按机制选择守恒、极限或去除作用的检查。 |
| 回接目标网络 | 核对实际接入对象、输入是否到达、状态是否传给下游；记录新增机制影响的基础发放、分布、稳定性及目标输出。默认静息任务不自动增加任务刺激。 |
| 目标比较 | 用一致的观测定义比较原模型、扩展模型、适用文献及实测；保存效应、误差、不确定性、代价和可区分候选的预测。仅检查受影响部分，复用仍有效的其他检查。 |

机制改变整体工作状态可能是预期结果，不能强求所有旧输出不变。若背景参数必须重新校准，将机制效应与重新校准的影响分开说明。只调研时给出具体协议和待运行状态；实施委托则实际完成适用运行。

没有目标效应时，先核对接入、数值及条件，再将结论限定于实际版本、协议和参数范围；不无限调参直到出现预期曲线，也不据一次失败否定整个机制。多个解释仍成立时保留它们及下一项有区分力的观察。

不改变原清单编号：细胞/空间/动力学主要对应 03–05，参数对应 06，连接/突触/输入对应 07–09，局部与跨系统过程对应 10，初始化/求解对应 11–12，观测/比较对应 13–14。逐项表记录受影响事项；模块索引关联实际代码、参数、步骤与检查。

使用现有 `task_plan.json`：已有工程扩展用 `modify`，新建用 `build`，仅调研用 `research`；不发明工具不支持的模式或 `features` 值。新增机制通过实际 `requirements` 和 `required_items` 登记。通用检查不判断全部生理接口、守恒与求解行为，相关数值检查需由本项目实现，记录其覆盖范围。

在 `docs/results.md` 说明最终神经元模型及新增机制、局部与网络中的真实作用、原模型—扩展模型比较及支持边界。按需保留状态/通量轨迹、空间场、机制效应与误差图；用本模型数据绘制，沿用[文献图学习](literature-figures.md)。记录对象、单位、时间、配置、运行和原始数据；大型场只按预定分析需求采样，预览不能成为唯一存档。静态、稳态或反演任务保存相应结构、残差或估计结果，不虚构尖峰与物理时间。
