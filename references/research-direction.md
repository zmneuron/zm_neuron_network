# 需求探索与方向选择

先识别来意。已有实验方案、草稿、相近论文或数据并希望反推模型时，进入[材料选模访谈](material-intake.md)。只提供现象或想法时用下表发现方向。选定路线后共用[六步主线](../SKILL.md)、[三档讨论](interview.md)和[科学问题推敲](scientific-questions.md)。

## 什么时候读这一页

| 当前状态 | 本页要求 |
|---|---|
| 用户没有明确目标，或不知道有哪些值得做的方向 | 先调研并提供方向选项，再根据选择澄清 |
| 用户已有目标，但对象、范围或成功标准不清楚 | 针对性追问，达到下面的理解程度后再确定方案 |
| 目标清楚、技术路线尚不明确 | 本技能主动调研方法、数据与开源实现并提出技术建议；仅对会改变目标或资源投入的取舍向用户追问 |
| 已授权探索或用户委托代选 | 说明依据后推进，不反复请示 |

多语种检索以本次检索日向前十年确定核心论文范围，早期关键模型、协议及数据来源保留关联。先从[共享索引](index/README.md)按问题和对象检索，再按[跨学科检索计划](index/search-plan.md)补查缺项。保留每批起止日、语言、平台、筛选深度和待查范围，区分已经检索但尚未定位与尚未检索。

## 五步过程

| 步骤 | 应完成的工作 |
|---|---|
| 整理背景 | 沿用已有回答和材料；缺少基本范围时，只问影响调研起点的少量问题 |
| 多方面调研 | 核对科学需求、最近邻研究、直接或替代数据、模型与代码、竞争解释、成本和缺口，提供来源 |
| 提出选项 | 给出少量实质不同的可行方向，比较问题与价值、依据、数据和关键比较、预期产出、成本及不确定性，并推荐 |
| 根据选择细化 | 按用户反馈补充必要调研和追问；仍难选择时，建议有助于判断的小范围调查或比较 |
| 确定正式方案 | 明确目标、对象与主要观测、数据条件、重要取舍、预算和交付范围，再在授权范围内实施 |

## 充分理解后再实施

对齐目标、产出和资源后可以比较方向。正式构建沿用[逐阶段的 95% 计算](interview.md#何时结束提问并进入实施)，同时解决全部关键取舍。科学上尚待检验的预测和参数可作为未知量进入模型，写明识别办法。

用户主要选择研究价值和取舍，技术路线由本技能调研提出；能够查证的技术问题主动查证，已经回答的问题不重复询问。只有新情况改变目标、主张或重要资源取舍时，才返回相应讨论。

## 与既有规则的衔接

- 方向确定后沿用或推荐交流档位，已经回答的研究取舍不再重复。
- 目标、数据和接受标准在选参前确定，沿用[实验约束校准](calibration.md) 与[运行比较](run-compare-optimize.md)，不另建目标表。
- 宿主或平台能力与工作目录按[宿主接入与能力边界](host-integration.md) 核实；科研记录仍按[工程组织](project-layout.md) 只保留一份当前状态。
- 探索档不编造数据或省略关键机制；精确档不自动采用多区室或大型网络。
