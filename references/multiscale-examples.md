# 跨尺度建模的两个可复算例子

当研究结论依赖跨区室的物质转运，或依赖从神经活动推算实验信号时，下面两例展示如何从原始量分别作出判断。所有数值和波形均为教学合成。接受范围仅用于本例，实际研究应在运行前按其协议、量纲和测量误差约定。

在含 `SKILL.md` 的目录运行以下命令。脚本仅使用 Python 标准库，输出每窗收支、每导指标和联合判断。[算例源码](../evals/multiscale_transfer_case.py)

```text
python -B evals/multiscale_transfer_case.py
```

## 离子收支与库存漂移

**问题。** 常量体积的胞外区室内，K⁺ 增加来自已记录的净转运，还是某笔转运重复入账？若收支相符，这个静息模型的胞外钾在观察期内是否足够稳定？

取三个连续的 1 s 窗。每窗两个 0.5 s 步的神经元非泵释钾率为 8、16 fmol/s，泵周转率为 3、5 fmol/s，胶质摄钾率为 0、2 fmol/s。非泵释钾向胞外为正。此处采用正向 Na⁺/K⁺ 泵周转，每次排出 3 Na⁺、摄入 2 K⁺、消耗 1 ATP。按步长积分，每窗非泵释钾 12 fmol，4 fmol 泵周转摄入 8 fmol K⁺、排出 12 fmol Na⁺、消耗 4 fmol ATP，胶质另摄入 1 fmol K⁺。因此胞外钾预期增加 `12 − 8 − 1 = 3 fmol`。若上游直接输出已扣除泵通量的神经元净释钾，应从该净值继续计算。

另一份输入单独给出四个边界时刻的胞外库存 100、103、106、109 fmol。从库存计算每窗变化，再减去由通量预测的变化。每窗残差绝对值上限约定为 10⁻⁹ fmol，期间各边界库存相对初始库存的最大绝对偏移上限约定为 2%。

| 输入或记账方式 | 每窗预测增加 | 每窗库存增加 | 每窗残差 | 最大偏移 | 判断 |
|---|---:|---:|---:|---:|---|
| 按记录计量 | 3 fmol | 3 fmol | 0 fmol | 9% | 转运解释了库存增加，静息钾漂移超限 |
| 同一笔胶质摄取计两次，沿用相同库存 | 2 fmol | 3 fmol | +1 fmol | 9% | 逐笔核对摄取的发送端与接收端 |
| 胶质摄取改为每窗 4 fmol，另给恒定库存 100 fmol | 0 fmol | 0 fmol | 0 fmol | 0% | 本观察期的两项要求均满足 |

在真实模型中，库存应直接取自保存的状态，与独立导出的通量对照。体积可变时逐时刻用相应浓度和体积换算物质的量。残差超限先查符号、单位、遗漏或重复的项。转运闭合但钾持续增加时，查释放与清除的差额、初始状态和准备期，按原时间窗重跑。若研究的正是急性积累，漂移本身就是待比较的预测。其他离子、分型放电和长时稳定性仍按各自的指标判断。[机制接入与数值检查](mechanism-extension.md#接口只展开实际采用的关系)

## 脑电幅度与谱形

**问题。** 校准后的头皮脑电振幅达到参考水平，是否也解释了高频活动？若结论只涉及细胞放电，按尖峰比较即可。若要解释头皮电位，先明确从源到导联的计算。多区室路线从包含电容项的膜段总跨膜电流与位置、朝向得到电流偶极矩，再经与电极匹配的头部导电模型得到电位，并按实验参考电极或蒙太奇重参考。电流密度须先按膜面积换为电流。单列源的规模、取向和同步假设，以及从电流、偶极矩到电位各步的单位。有独立约束的等效偶极也可用于相应问题。共享索引中的 `o_breadth_lfpy_eeg` 定位了一个公开的正演模拟。[Hagen 等，图 5E–G](https://www.frontiersin.org/journals/neuroinformatics/articles/10.3389/fninf.2018.00092/full)

本例从传感器电位开始，各导使用相同的外部参考。开发条件的 A、B 两导物理均方根幅度（RMS）为 1.5、0.5 µV，合成参照为 3、1 µV。以导联 RMS 作过原点最小二乘得到共同电压倍率 `g = 2`，冻结后用于另一合成条件的所有导联。两组波形分开生成。评价窗长 2 s，采样率 200 Hz，去均值后在同一矩形窗计算单边功率谱。高频占比是 30–45 Hz 积分功率除以 1–90 Hz 积分功率。

本例按 µV 的绝对误差选倍率。若实际研究以每人的相对幅度为目标，按[多人脑电标定](fit-recordings.md#多人的脑电如何标定一个共同电压倍率)选择损失与聚合顺序。

本例预先要求三导均可用。原物理电位和参照的峰峰值均须至少 0.10 µV。可用导联的标定 RMS 与参照之差至多 0.05 µV，高频占比之差至多 3 个百分点。

| 导联 | 物理 → 标定 RMS | 参照 RMS | 物理 → 标定高频占比 | 参照占比 | 逐导判断 |
|---|---|---:|---|---:|---|
| A | 1 → 2 µV | 2 µV | 25% → 25% | 4% | 幅度达标，高频占比高出 21 个百分点 |
| B | 0.75 → 1.5 µV | 1.5 µV | 4% → 4% | 4% | 两项均达标 |
| C | 0 → 0 µV | 1 µV | 无法估计 | 4% | 原信号平坦，保留质量失败，频带占比留空 |

同一信号乘以非零常数，在相同参考、线性处理、入选窗和非零总功率下，RMS 乘以 `|g|`，绝对功率乘以 `g²`，相对功率保持不变。A 导 30–45 Hz 绝对功率由 0.25 增至 1 µV²，参照为 0.16 µV²。调整共同倍率无法消除这项谱形偏差。下一步可在同一窗依次比较膜电流谱、偶极谱、投影后和重参考后的导联谱，检查源间同步与投影抵消，并查明 C 导何处变平。三导联合校准尚未满足。

实际研究按原先登记的参考方式和质量规则交付。若更改参考、剔除窗口或改用其他估计方法，单列重分析及其影响。用过的开发记录、检验数值稳定性的新网络种子、未参与选择的生物记录分别注明。本例只有合成信号，检验的是分析方法。[实测校准与失配处理](calibration.md#均值达标后的失配仍需处理)
