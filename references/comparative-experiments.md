# 设计能区分解释的比较实验

当主问题涉及跨对象推广、扰动归因、方法优劣、在线控制或功能恢复时，从下表选择会改变该结论的比较。把选择写回原有方法表、任务计划和结果报告。描述性复现可只采用其中与原问题相关的一项。

| 想回答的问题 | 建模时先作的决定 | 决定结论的观测 |
|---|---|---|
| 能推广到什么新对象？ | 指定新试次、新网络、新记录日或新动物，按该层真实来源留出。模拟与实测分开。 | 留出来源的交集、各层实际个数、冻结后的逐独立单位表现。 |
| 某种改变造成了多少影响？ | 列出要改变的因素及应相同的背景。为每次配对生成一次外源输入，将同一份实际输入分发给相关条件。 | 逐对象核对恒定因素的实际值，再估计预定尺度上的配对差。反馈引起的内生轨迹可自然分开。 |
| 方法何时更有用？ | 给出决策时刻可用的信息、训练与选择开销、目标任务和最强的适用比较方法。 | 同等可用信息和预算下的原始表现、差异及其不确定性，另列真实使用成本。 |
| 一种机制、信息损失或功能恢复足以解释结果吗？ | 选择能复现表象的简单解释，再设计会让两种解释给出不同预测的条件。 | 分别观察模型内部读数、可测信号和功能结局，说明哪些解释仍然相容。 |

## 从同源记录开始划分

先写明独立单位及其从属关系，例如动物 → 记录日 → 试次 → 时间窗，或结构实例 → 扰动实例 → 输入实现。数据库索引、复制后的文件名和重新编号的试次只用于定位。跨动物结论按原动物身份划分，同一记录的裁剪、增强和重导出继承原归属。只评价同一网络的新输入时可以共用网络，报告这一条件。要同时推广到新结构和新扰动时，两者均需留出并重复，分别展示条件间变化。

在看结果和拟合预处理前固定开发与评价成员，按折登记训练、选择超参数、标定输出以及最终评价的实际用途。一次评价若用于修改模型，就把它计入开发，另设冻结后的评价。查两个运行的原始身份交集用 `disjoint_sources`，单表多组划分用 `disjoint_units`。真实来源不明时保留“独立性未确定”。模拟输入可另比实际送达的时序或共同前缀，结合生成代码判断相同部分是预定的确定性刺激还是复用了应独立的随机变化。

## 在生成时区分共享和重抽的因素

为每个随机过程明确“在哪些单位之间共享、在哪些单位重抽”。可以复用[随机输入示例](../assets/experiment_inputs.py)。例如比较同一切片上两个预测方法，固定切片结构，开发池和评价池各自生成新刺激，评价池内的两种方法使用同一刺激。以下代码中 `trial` 是池内试次序号。

```python
from random import Random
from experiment_inputs import input_seed

def pulse_times(pool, slice_id, trial):
    seed = input_seed(17, pool=pool, source="stimulus", unit=(slice_id, trial))
    return sorted(Random(seed).sample(range(500), 8))

train_pulses = pulse_times("development", "slice-04", 1)
test_pulses = pulse_times("evaluation", "slice-04", 1)
# Pass the same test_pulses to each paired method.
```

其他随机过程使用自己的 `source`，按设计决定 `unit` 是否包含结构、扰动、会话或试次。预生成跨条件固定的掩码、参数或外部事件，可避免某个分支多抽一次随机数改变后续输入。把实际送达值从施加输入的代码位置写入逐单位表，或保存规范化实际输入内容的摘要及其生成方法。给实测记录改名、给同一数据换种子、仅记录计划参数，都不足以证实独立或配对。两个独立生成的随机输入也可能偶然同值，须结合来源判定。

## 比较细胞数量与突触强度

若同一扰动有两个实现，在条件方案中分别记录两者的实际运行标识，例如 `adverse_count` 与 `adverse_weight`。部分总览图可以由其中一组代表，但主问题应能定位到两组以及它们的直接差值。显示名可以翻译，取数条件沿用运行中的原标识。

减少某类细胞和减弱一条投射可以产生相似的群体平均值。先决定问题是比较两种修改的**总后果**，还是在**给定实际抑制输入时**检验接触分布的作用。前者保留回路补偿，后者需在预定窗口、靶细胞和容差内匹配所指的量。电导用 nS，电流用 pA，电荷按电流积分。明确比较的是这条投射还是包括背景在内的全部抑制。细胞数乘单突触电导只给出名义设置，实际作用还取决于连接、放电、延迟、衰减和膜电位。

- 从同一母网络保留细胞身份和存活细胞间应共用的连接、位置及外部事件。可以先生成完整实例再屏蔽指定细胞，或按稳定的细胞和连接标识生成。用原始实例检查一条受影响投射和一条应当保持的投射，再核对实际输入。计算与设计要求独立重抽网络时，按两种网络生成方案估计总体差异。保留各自内生放电和回路反馈。
- 比较窗内分别记录目标投射、其他回路和背景送达的量。需要论证抑制分布时，保留逐靶细胞电导或足以重建它的事件、实际权重和时钟，报告均值、绝对离散度、相对离散度及零输入比例中能回答问题的读数。归档允许重建时，先把各来源加回，与已存总轨迹核对。若两组尚未匹配，可保留原比较，再在开发实现上调整强度、冻结规则，用新实现检验仍存在的差异。分别报告通路匹配与总量匹配。
- 逐独立单位直接计算两候选的差。共享参照 B 时，`(A−B)−(C−B)=A−C`，差的区间取决于同一单位两次读数的协变。两组各自相对 B 的误差线不能回答这个问题。能分辨模拟条件的指标、能预测下游功能的指标、能鉴别真实病因的记录，各自需要相应比较。

对按设计可配对、每个独立单位每个条件一行的 CSV，可用[逐单位比较工具](../scripts/paired_readout.py)复算均值、每对差值和配对均值的双侧 95% Student t 区间。例如 `python scripts/paired_readout.py results.csv --unit-id network --arm condition --column delivered_g --left fewer --right weaker --unit nS --expected-ids 1 2 3`。区间以不同单位的差近似独立、均值的 t 区间适用为前提。一对只报告差值。层级抽样、明显偏态或机制等效按其设计选用对应方法。配对身份、预定成员和实际输入仍从构建/运行记录核对。

## 在模型的正常入口测试信息与时间

逐步列出预处理、分窗、对齐、筛选、拟合、选择和推断实际读取的量、可得时刻及取得代价。独立测试时只提供部署所允许的信息。在接口处移去真值、未来样本或人工标注，观察同一时刻的输出是否还能按预定方式产生。需要理想状态、真实标签或预知未来的比较可保留，并标明其额外信息。已知实验时钟只有在正式使用时也可获得，才能作在线输入。

有状态的模型须约定试次、会话或连续记录边界，说明状态重置、预热、延迟和缺测处理。保留实际控制系统使用的逐时刻输出。离线复算按相同边界和时间顺序回放，按“会话 × 试次 × 时刻 × 输出分量”对齐。改变下一段数据，先前预测应维持在事前数值容差内。独立试次可再改变前一试次的末值，检查下一试次的初始化。任务规定跨段继承状态时，用连续回放检查继承。因闭环而改变后续记录时，固定同一观测序列检查实现等价，另用真实反馈运行比较任务效果。

## 为归因与方法比较选择有判别力的参照

- 先看任务规律或简单机制本身能解释多少。可测试只用时钟和合法任务线索的预测、仅共有输入的网络、或已有成熟方法。若输出模板预先给定，在能区分机制的留出条件上比较。记录最近邻方法的来源、适配、调参范围及合理的运行结果。
- 分辨“现有读出失配”与“信号可利用程度改变”时，同时估计固定读出和在剩余观测上重新拟合的表现。用样本量或学习曲线判断拟合是否充分。对已知可逆变化可加使用模拟真值的理想校正，在明示假设与方法族内给出参照。所有已试读出均失败，仍需说明未覆盖的读出、噪声和样本量。
- 比较适应方法时，分别计数可用无标签记录、带标签对象或时长、调参/标定用量和计算开销。若问题是同成本优劣，按相同剂量比较，必要时画出剂量—效果曲线。若目标是现实可用的两套不同方案，可保留各自成本，结论限定为这两种资源配置。
- 对两因素的交互，配齐参照、A、B、AB，配对预定的共同因素，分开会同时改变的噪声或其他机制。对“数值越大表示结果越大”的读数，在原定尺度计算 `Y_AB − Y_A − Y_B + Y_0` 并说明符号。读数改用损失尺度时相应说明。检查指标的非线性、天花板或地板能否产生同一现象，再判断机制解释。

## 从逐单位数据写出结论

先给每条件的原始数值、单位、功能成功数/总数、失败和缺失。按独立单位估计配对差与区间，重复测量保留其层次。单位太少则展示各单位值、方向与范围，明确精度。代理读数与功能结果分别报告，各用自己的定义和分母。恢复比例先固定表达式，如 `(干预 − 受损)/(参考 − 受损)`，声明是群体均值之比还是逐单位比值的汇总，给出原始差值及分母接近零的事前处理，保留过度恢复与恶化。不同估计量可得不同数值。

从逐单位表生成图、正文和摘要中的数字。核对图上的样本点、误差线、图注和文字采用了同一对象、样本数、估计量与版本。最终判断注明适用对象和条件。模型内的反例、预测或阴性结果可构成贡献，推广到真实生物对象须有该层未用于选择的可比数据。

需要复算恢复比例时，使用 `operation: recovery_fraction`。在同一宽表中每个独立单位一行，`row_key` 指定单位键，`column`、`reference_column` 和 `impaired_column` 分别读取干预、参考和受损读数。三列单位相同，结果为无量纲比例。`aggregation` 明确选 `ratio_of_means` 或 `mean_of_ratios`。按原观测单位填写非负的 `denominator_floor` 和依据 `floor_basis`。前者对总体均值之差判定分母，后者对每个单位判定，分母绝对值小于或等于下限时该估计量未定义。此时仍报告原始量与绝对差。正式取数定义填写三列共用的 `column_unit`，各列分别与数据说明核对。例中两单位的“干预、参考、受损”为 (5,10,0) 和 (3,2,0)，两种算法分别得到 2/3 和 1。

## 把原则接到已有检查

在 `review.questions[].required_design_dimensions` 列出该主张依赖的维度，在 `review.scientific_checks` 登记同题的 `comparison_design`。下例给出其中与读数有关的字段。每项另填原检查要求的 ID、问题、说明和方法出处。使用已完成运行登记的原始 CSV，选取行必须能定位真正送入模型的量。[完整字段及结果处置](scientific-constraints.md#预注册比较与实际执行记录)

```json
{
  "rule": "paired_values",
  "expected": true,
  "pair_by": ["slice_id", "trial", "pulse"],
  "source": {"run_ref": "runs/method_a/run.json", "csv_ref": "runs/method_a/input.csv", "column": "delivered_ms"},
  "control": {"run_ref": "runs/method_b/run.json", "csv_ref": "runs/method_b/input.csv", "column": "delivered_ms"},
  "abs_tolerance": 0.001,
  "unit": "ms",
  "tolerance_basis": "本例记录器的时间分辨率为 0.001 ms"
}
```

将同一例换到跨动物评价时，使用 `disjoint_sources` 并读取两侧原动物 ID。用配对规则做在线回放时，指向实际在线输出与独立重算值，按试次、时刻和分量配对。程序能核对已登记记录中的交集、逐键一致性和数值偏差。来源是否真实、是否选对独立层级、两个方法共同遗漏了哪些对象或时刻，仍须检查数据来源与预定成员，可另用 `levels` 核对覆盖。故意复用一个留出来源、错换一个配对值或删去所有选中行，检查相应比较确实能暴露误差。

设计依据可参见 Morris 等关于模拟研究的目标、生成过程、估计量与精度，Kapoor 与 Narayanan 关于独立性应与推广主张相符的分析，以及 Wilson 与 Collins 关于用已知模型检验机制可区分性的算例。[Morris 等，2019](https://doi.org/10.1002/sim.8086) · [Kapoor 与 Narayanan，2023](https://doi.org/10.1016/j.patter.2023.100804) · [Wilson 与 Collins，2019](https://doi.org/10.7554/eLife.49547)
