# 衡量后续模型的科研质量

这里的分数用于比较同类项目的成熟度。判定某项预测是否达到用途要求时，使用原定容差、实际误差和适用的独立检验；完整模型能否结束按[逐阶段回查与结束条件](../references/project-checks.md#逐阶段回查与结束条件)判断。

评估对象是一份具体问题、模型、运行和报告。先按研究主张选指标，再看所得结果。以下权重供原创研究比较项目成熟度。指定复现、软件检验或纯理论任务沿用原目标，原定不适用的维度单列，并用实际适用的总权重归一到 100。跨版本比较必须使用同一任务、权重和判据。

| 维度 | 分值 | 低分到高分的依据 |
|---|---:|---|
| 问题重要性 | 15 | 对象与用途含糊 → 可测且有相关实测或理论背景 → 最近邻工作留有明确缺口，至少一个可能结果会改变解释、测量或设计。 |
| 方法创新性 | 20 | 只列组件 → 能运行且有明确简单参照 → 在相同可得信息和合理成本下识别新增能力、适用条件或足以推翻已有解释的反例。复现工作可预先另定义本维度。 |
| 实验完整性 | 20 | 条件或独立单位不清 → 已执行主要对照但仍有关键混杂 → 宣称推广的层级、固定与重抽因素、相应的留出和辨别实验均有实际记录。 |
| 结果的科学判别力 | 20 | 只有汇总均值 → 给出分项效应和单位但精度有限 → 独立单位上的效应、区间或明确的精度边界足以回答原题。涉及用途时有功能读数。充分有力的阴性结果可得满分。 |
| 可复现性 | 15 | 缺少关键输入或运行入口 → 可复算主要表格 → 从保存的配置和输入重建关键比较，主效应及适用的在线逐时刻结果在事前容差内重现。 |
| 论文叙事 | 10 | 结论超出数据 → 文字能定位主要结果 → 每句核心判断与对照、估计量、图和原始读数一致，能说明相对既有工作的贡献与未决解释。 |

每项可取权重的 0、25%、50%、75% 或 100%。0、50%、100% 分别对应表中三个锚点，中间档须写出已满足和仍缺的具体依据。报告总分与各维度、扣分依据并列。每条主要主张另列“有支持、无支持、尚难判断、尚未评价”。来源重叠会限制相应推广主张，未取得实测留出会限制现实外推，同一模型的其他实得结果仍可评价。期刊适配、研究价值和投稿判断另作学术判断。

## 可从下一个项目直接记录的指标

| 适用主张 | 从哪项记录计算 | 判读标准 |
|---|---|---|
| 独立推广 | 每折列开发与评价的原始来源数、交集数及未明来源数，另列网络、记录日、动物等有效独立单位数。 | 所称独立层面的交集为 0 且来源已知。可有意共用的层级预先写明。统计精度按独立单位评估。 |
| 同背景归因或等成本比较 | 已配对的唯一键数 / 应配对总数、两侧缺项和重复数、实得背景差异；列训练、选择、标定的标签量与总开销。 | 主张完全匹配时，预定键覆盖 100%，重复和非预期缺项均为 0，实值差异在预定容差内。允许缺失、剂量不同或观察性分析时需另报分母、缺失机制和适用范围。 |
| 在线运行 | 实际输出与相同观测的回放输出按键比较，列被遗漏的键数、不合容差数、最大绝对误差。分别更改未来输入及前一独立试次末值，观察相应前缀或初始化。 | 在声明等价的窗口内逐点满足预定容差，输入可得性测试与状态约定一致。在线闭环效果另看任务读数。 |
| 量化的主效应或功能结局 | 逐独立单位计算差值、原始水平和预先定义的区间。比例报告分子/分母、分母接近零的处理，阈值事件报告成功数/有效总数。 | 判读基于事先确定的最小有意义效应、对立解释与精度。样本少、数据缺失或区间跨过关键值时保留不确定性。 |
| 生物学外推与复现 | 分别统计在同版模型中有可比实测、且冻结后另有独立实测的主要预测；列已重算的关键数值 / 预定核对总数，以及同一来源的图文不一致数。 | 生物推广限于实际独立实测覆盖的对象与条件。要求可复算的数值覆盖 100% 并满足事前容差，图文矛盾在交付前解决。 |

### 完整研究的四项交付指标

| 评估项 | 如何计数与判读 |
|---|---|
| 主要干预比较 | 分母是运行前登记的主要干预效应。逐项核实实际输入、名义计数与内部更新的对照，核算独立样本的有效输入减匹配零作用差值，并在两份报告给出均差和 95% 区间。完整覆盖率应为 100%。逐项标记支持、方向相反或尚难判断，另列未完成的比较。无主要干预的研究记不适用。 |
| 结论与来源 | 主要结果关联实际来源及报告原句的比例应为 100%。逐条核对独立生物验证所指的实验对象、刺激、时间窗、读数定义、单位及其与开发数据的重叠；将模拟结果误列为独立实测的次数应为 0。 |
| 结果图的信息量 | 完整研究至少 6 幅实算结果图，通常 6–8 幅。每幅记录它回答的问题、独立样本和底层数据；模型示意、多面板拆分、重复格式或相同数据的无意义重绘不增加计数。评阅人逐图核实其新增信息。没有足够数据时记录实际数量及缺少的比较。 |
| 数值复算与阅读版重建 | 从空目录分别记录主表是否重现、阅读版是否重建。所报主数值、版本和图件在 Markdown、离线 HTML 与当前输出间应全部一致；坏图、裁掉的应显示候选和遗漏的主要图均应为 0。单列未能实际打开检查的阅读环境。 |

## 检验技能升级是否产生实际收益

保留旧版与候选版，用相同材料、问题和约定计算预算分别交给未看答案的执行者，执行顺序或分配在看结果前确定。试题要同时有真实缺陷的反例和设计正确的正例，例如同数异物、同表乱序、合规共用网络、应独立的动物重复、连续状态合法继承。应在运行前写下已知事实、评分办法和涉及哪些维度。独立阅读模型时只提供题目、原始资料和指定版本，不提供参考答案或生成器。

分别报告检出的异常数/已知异常总数、正确保留的设计数/有效设计总数、无依据的结论数/主结论总数、可重算主结果数/主结果总数，以及六维评分的配对差。记录执行时间、人工返工与实际资源，避免以更大预算换取表面增益。对全新、尚无标准答案的研究可由独立评审按事前标准评分，并保留分歧。一次案例可验证特定能力。要评价整体提升，应在多种新任务上重复并报告任务间的差异，例如数据解码、反馈系统和生物机制模型各自的表现。

[合成切片任务生成器](comparison_transfer_case.py)可用于练习。运行 `python -B -X utf8 evals/comparison_transfer_case.py --workspace <新目录>`，只向执行者提供新目录。熟悉该算例后更换数据、缺陷与盲题，再用于评估迁移。

检验新模型构建时，可运行 `python -B -X utf8 evals/adaptation_transfer_case.py`。该例对一个带放电适应的点神经元和一个外部驱动较弱的点神经元，先在持续刺激下匹配平均发放数，再用冻结后的参数和新噪声比较双脉冲响应。输出两种模型每次试验的原始计数，可检查同一校准读数容许几种解释以及新协议能否区分它们。[机制比较算例](adaptation_transfer_case.py)
