## 核查结论与实际调整

文档的主线可以采用：场景需要生物学依据、明确作用位置、时间协议与对照，后果由模型产生。需要补强的是每段推断的支持范围，以及这些内容如何进入实际方法、配置和最终文字。没有把原文所有例子和八步次序再复制成一套强制流程。

| 原文思路或容易产生的理解 | 本次判断 | 已落实的处理 |
|---|---|---|
| 从参考模型进入特殊场景 | 可采用，但目标场景应在选型时参与决定；现有参考不一定健康或适合新问题 | 在原主线中增加条件性入口，分别选择问题、范围、表示和观测；允许复用、扩展参考或重选范围。 |
| 先查变化、再查原因、再改模型 | 作为研究关系明确保留；原因可能尚未确定 | 把实验观察、机制支持、迁移推断和探索假设分开；未知原因可比较候选，不编造定论。最终方法与结果均逐项标明。 |
| 每项改变都有数值映射 | 必需，但一个终点通常不独自决定多项内部变化 | 记录原始测量与条件、转换、单位、作用对象、前后关系和最终生效值；表达、数量、电导、动力学及群体读数分别处理。 |
| 防止重复施加 | 保留，不能误解为一次只准改一个参数 | 区分直接作用与内生后果；独立直接作用允许联合改变，已包含作用的总因子、归一化和旧近似逐项核对。 |
| “最小因果充分集合” | 实施前通常不能证明真实系统的因果充分性 | 改为可检验的最小机制组合；用中间量、终点和判别对照评价其作用，不把组件接通写成病因证实。 |
| 新增机制后建立正常参考 | 对正常生理过程成立；不能强制所有状态为零或所有输出完全不变 | 比较扩展参考与场景，原模型用于检查表示变化；正常数据校准与场景拟合分开，显式过程接管旧近似时明确替换。 |
| 连续暴露、撤除和恢复继承状态 | 保留，并补足实际续算条件 | 除细胞状态外，按后端处理突触历史、共享介质、事件/延迟、时间和随机过程；新增维度说明准备与对象对应。只复制旧电压不称完整续接。 |
| 正常、场景、场景加干预作为核心条件 | 可用于描述；干预归因还需要时间与背景匹配 | 场景对照继续到同一终点，按问题加入假刺激/载体；自然恢复与干预效应分开，健康加干预按特异性/交互问题加入。 |
| 所有条件都“优化” | 必须明确优化对象 | 校准模型、估计场景与选择干预分别定义；真实病理静默、非平稳演化或指定复现中的静默不为满足默认基础率而被删除。 |
| 脑区与连接数据决定大网络 | 需要经过相应表示的映射 | 范围与分辨率独立选择；区域边的语义、细胞连接生成、总量/单位量、缩放和接口分别定义；功能反相关不直接变成抑制突触。 |
| 一个问题累计成本并以判定结束 | 保留现有规则，不额外增加预算审批体系 | 复用当前进度、任务关联和既定预算，失败与重跑不清零；阴性和无法区分均可结束已完成的研究单元。 |
| 再增加一份场景说明与展示界面 | 采用按需记录，界面不作为默认要求 | 简单场景并入当前方法，复杂时抽成一份被引用说明；当前源码共用，条件配置与全部支撑结果保留。没有新增通用软件框架或格式。 |

## 实际调研及读取范围

实际检索包含以下问题与检索式，并从用户文档给出的 DOI、作者仓库继续定位方法。此处记录对本次决定有用的操作，不把原文的既往阅读声明列作本轮完成工作。

- 氧与泵的表示：`"Mechanisms underlying pathological cortical bursts during metabolic depletion" oxygen pump ATP`；核查方法中的氧储库、离子和泵关系，并读取作者求导实现。
- 药物映射：`"Thalamocortical control of propofol phase-amplitude coupling" conductance decay`；核查 GABA_A 幅度、时程和实际出图脚本的覆盖值。
- 跨区与缩放：`"A multi-scale layer-resolved spiking network model" downscaling`；核查区域/层/群体构建和作者缩放函数。
- 连接与多解：`"The challenge of mapping the human connectome" false positive streamlines 2017`；`"Similar network activity from disparate circuit parameters" Prinz 2004`。
- 病理与补偿、结构改变：检索 Dell’Orco 等的 atrophy/compensation 原研究及 Hong 等的 complement/synapse loss 原研究；本轮可用的正文读取深度有限，未提取参数或移植机制。
